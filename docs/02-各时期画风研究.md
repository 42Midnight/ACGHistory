# 各时期人物画风研究

更新：2026-11-04。以下是编辑样本的解释性观察，不是行业统计；每期均保留并行路线。不研究背景与场景，不从画法推导预算、软件或制作流程。尚未完成逐图对应的观察，保留为待检验线索。

# P1｜1996–1999：赛璐璐的余温

## 观察入口

细线、长身、冷色只是部分案例；圆润轮廓、写实五官与装饰性大眼同样存在。

## 九维度观察

| 维度 | 对照时看什么 |
|---|---|
| 线 | 纤细轮廓与弹性粗线并行 |
| 眼 | 装饰性大眼与较克制的眼型并存 |
| 脸 | 削瘦下颌、突出的鼻部与圆脸分别可见 |
| 色 | 比较人物固有色与阴影边界，不将冷色概括为全期 |
| 身 | 修长体态与圆润的活动轮廓形成对照 |
| 发 | 大片发束和连续高光可作观察线索 |
| 演 | 克制表情与夸张变形都有样本 |
| 质 | 漫画线稿、游戏绘与动画平涂需要分媒介比较 |
| 比例 | 没有统一测量，不给出全期头身数值 |

## 同期差异

把EVA的修长轮廓与《魔卡少女樱》漫画的装饰性五官并排观察。作品之间的差异提示我们：同一年已有不同路线，不应把其中一条宣布为所有作品共同的主流。

## 与相邻时期的关系

沿着同一维度比较，不预设单向进步。这一期只以EVA为起点，不另设此前历史。下一期的选择用于寻找连续与差异，不把边界年当成突变。

## 案例入口

- 1996《新世纪福音战士》：细线、长身、冷色、记号。
- 1996《天空之艾斯嘉科尼》：端正、少女漫画、异世界。
- 1996《魔卡少女樱》：少女漫画、大眼睛、装饰性。
- 1996《樱花大战》：跨媒体、端正美形、大正浪漫。

# P2｜2000–2004：『萌』的语法化

## 观察入口

大眼与小鼻口在部分样本中突出；写实脸、棱角轮廓与装饰性衣纹提供同期对照。

## 九维度观察

| 维度 | 对照时看什么 |
|---|---|
| 线 | 注意外轮廓与五官线之间的粗细差异 |
| 眼 | 眼型与眼距形成鲜明的设计辨识度 |
| 脸 | 小鼻口与成人骨点表现并存 |
| 色 | 平涂色块与贴图式人物衣装可相互对照 |
| 身 | 细长四肢并非唯一选择 |
| 发 | 尖束、圆束与高光带组织角色轮廓 |
| 演 | 比较相同人物的平静与夸张表情 |
| 质 | 《岩窟王》的服饰纹理是区别于常见平涂的案例 |
| 比例 | 比例服务于具体人物设定，不按年代统一归纳 |

## 同期差异

把《高达SEED》的记号式五官与《攻壳SAC》的成人脸部结构并排观察。作品之间的差异提示我们：同一年已有不同路线，不应把其中一条宣布为所有作品共同的主流。

## 与相邻时期的关系

沿着同一维度比较，不预设单向进步。上一期已有的画法可以延续，也可以与新的设计并行。下一期的选择用于寻找连续与差异，不把边界年当成突变。

## 案例入口

- 2000《特别的她》：剧画、变形、作画。
- 2000《银之苏玛》：平井脸、鼻梁消失、眼距。
- 2000《蜂蜜与四叶草》：水彩、潦草线条、女性向。
- 2000《村田莲尔》：极细线、复古未来、无国籍。

# P3｜2005–2009：角色主导的时代

## 观察入口

圆脸、小鼻口与成组的发束便于辨识；不同设计师的线条与表情仍有明显差异。

## 九维度观察

| 维度 | 对照时看什么 |
|---|---|
| 线 | 圆润轮廓与棱角线条形成对照 |
| 眼 | 大眼的形状与高光布局因设计师而异 |
| 脸 | 短下巴、小鼻口在部分角色中突出 |
| 色 | 明亮色块与较少阴影是部分样本的观察入口 |
| 身 | 站姿重心与肩部松紧参与角色性格表达 |
| 发 | 发束和刘海的轮廓具有识别功能 |
| 演 | 日常微表情与夸张喜剧脸并行 |
| 质 | 漫画、轻小说插画与动画图像用途不同 |
| 比例 | 不以圆脸推断所有作品都幼态化 |

## 同期差异

把《轻音少女》的圆润轮廓与《天元突破》的棱角与夸张体态并排观察。作品之间的差异提示我们：同一年已有不同路线，不应把其中一条宣布为所有作品共同的主流。

## 与相邻时期的关系

沿着同一维度比较，不预设单向进步。上一期已有的画法可以延续，也可以与新的设计并行。下一期的选择用于寻找连续与差异，不把边界年当成突变。

## 案例入口

- 2005《AIR》：京阿尼、大眼、细腿、Key。
- 2005《交响诗篇》：松弛线条、生活感、作画派。
- 2005《好想告诉你》：柔光、圆脸、纯爱。
- 2005《深渊传说》：端正美形、JRPG、稳定供给。

# P4｜2010–2014：信息量爆炸

## 观察入口

部分作品细化虹膜、发束与人物肤色；另一些作品保持平面化与强烈的记号。

## 九维度观察

| 维度 | 对照时看什么 |
|---|---|
| 线 | 局部细节与面部留白可以同时存在 |
| 眼 | 部分作品强化虹膜层次，另有强记号式眼睛 |
| 脸 | 下颌与鼻部的结构在不同路线中差异明显 |
| 色 | 比较肤色、人物阴影和发束投影之间的关系 |
| 身 | 动作型身体与日常体态共同构成样本 |
| 发 | 细发丝与块状分组并存 |
| 演 | 眼睑、眉口的细微变化仍需与大幅变形对照 |
| 质 | 细化材质不意味着每个镜头都具有同等细节 |
| 比例 | 相同公司内部也有不同设计师的比例选择 |

## 同期差异

把《冰菓》的眼部细节与《魔法少女小圆》的平面记号并排观察。作品之间的差异提示我们：同一年已有不同路线，不应把其中一条宣布为所有作品共同的主流。

## 与相邻时期的关系

沿着同一维度比较，不预设单向进步。上一期已有的画法可以延续，也可以与新的设计并行。下一期的选择用于寻找连续与差异，不把边界年当成突变。

## 案例入口

- 2010《无头骑士异闻录》：锐角、都会、群像。
- 2010《四叠半神话大系》：变形、透视、实验。
- 2010《huke》：厚涂、暗色、机械少女、跨媒介。
- 2010《尼尔 复制体》：脆弱感、荒废、情感。

# P5｜2015–2019：全球化与样式分裂

## 观察入口

精细脸部、力量型轮廓与简省表情并行。人物画风的差异，无法由一条精细度曲线解释。

## 九维度观察

| 维度 | 对照时看什么 |
|---|---|
| 线 | 力量型外轮廓与纤细简笔同年可见 |
| 眼 | 装饰性眼部与克制的眼睑处理并行 |
| 脸 | 五官可以追求骨感、圆润或平面化 |
| 色 | 人物色彩可精细也可简省，不以层数排高低 |
| 身 | 比较力量姿态、写实体态与松弛站姿 |
| 发 | 发丝的装饰密度是一个可比较的局部维度 |
| 演 | 微表情与高强度变形分别服务不同角色 |
| 质 | 织物、金属与肌肤的表现需要结合具体图像 |
| 比例 | 不把风格路线直接解释为预算等级 |

## 同期差异

把《紫罗兰永恒花园》的装饰密度与《利兹与青鸟》的简省轮廓并排观察。作品之间的差异提示我们：同一年已有不同路线，不应把其中一条宣布为所有作品共同的主流。

## 与相邻时期的关系

沿着同一维度比较，不预设单向进步。上一期已有的画法可以延续，也可以与新的设计并行。下一期的选择用于寻找连续与差异，不把边界年当成突变。

## 案例入口

- 2015《一拳超人》：作画狂欢、简化脸、动作。
- 2015《吹响！上低音号》：写实日常、呼吸感、京阿尼。
- 2015《血界战线》：写实线条、过度装饰、美式影响。
- 2015《米山舞》：电影感、光与色、动画师转插画。

# P6｜2020–2025：多极化

## 观察入口

眼睛记号、松弛表情与材质化角色并存；跨媒介传播让同一时期的差异更加可见。

## 九维度观察

| 维度 | 对照时看什么 |
|---|---|
| 线 | 简省轮廓与复杂装饰继续并行 |
| 眼 | 星瞳等高辨识记号与安静眼型同年可见 |
| 脸 | 人物脸型不构成单一的新标准 |
| 色 | 平涂与材质化的角色用色互相参照 |
| 身 | 平面设计与立体角色都可讨论人物姿态 |
| 发 | 发束轮廓、染色与高光是不同观察层次 |
| 演 | 网络式夸张表情与克制表情并存 |
| 质 | 立体角色的材质表现也属于人物研究 |
| 比例 | 跨国与跨媒介案例须标明版本和制作地区 |

## 同期差异

把《葬送的芙莉莲》的克制表情与《我推的孩子》的眼部记号并排观察。作品之间的差异提示我们：同一年已有不同路线，不应把其中一条宣布为所有作品共同的主流。

## 与相邻时期的关系

沿着同一维度比较，不预设单向进步。上一期已有的画法可以延续，也可以与新的设计并行。研究止于2025年，不据此预测后续趋势。

## 案例入口

- 2020《咒术回战》：记号化、留白、表情符号。
- 2020《别对映像研出手！》：手绘动画论、线条表演、过程。
- 2020《世界计划 缤纷舞台！》：赛璐璐3D、配信、虚拟歌手。
- 2020《LAM》：高饱和、撞色、视觉冲击。

# 如何理解长期变化

线条可以从复杂变简省，也可以反向增加细节；眼睛和发束往往承担辨识作用；身体和表情同样重要。以上是比较线索，没有证据支持「每隔5—7年必然反向修正」的周期律。

鼻子的画法不能单独判断年代。宣传图、设定图和正片不能当成可直接互换的证据；角度、景别、材料版本与设计署名都需同时核对。
