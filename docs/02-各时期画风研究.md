# 各时期画风研究

> 这一章是全部前期准备的核心。每一期按同一个模板写：**时代条件 → 主流画像（九维度）→ 关键做法 → 代表作者 → 同期异质探索 → 前后差异**。最后给出跨期总表与五条长期趋势。
> 只谈人物，不谈背景；技术只作为画风的成因出现。

---

## 怎么读「主流画像」

每个维度给出的是**该期最普遍、最可复制的做法**，不是「最好的做法」。判断依据是：把它放到同期任意一部中等成本作品上，是否基本成立。不成立的部分，写在「异质探索」里。

---

# P1｜1996–1999：赛璐璐的余温

## 时代条件

赛璐璐仍是主要工艺，但摄影（合成）已经数字化：人物与背景的合成、光效、滤镜都在后期完成。EVA 之后深夜档开始容纳「作者性」作品，OVA 市场还在，PC 与 PS1 让游戏人物第一次有了「脸」的概念。整体气氛是**世纪末**：不安、封闭、内向。

## 主流画像

| 维度 | 该期的普遍做法 |
|---|---|
| **线** | 细、均匀、几乎不做「入り抜き」（起笔收笔的粗细变化）；轮廓线偏黑褐而非纯黑；头发用大片色块＋一条连续白带作高光；线「怕断」，所以转折处常用小圆角 |
| **眼** | 杏仁形或斜切形；上眼睑一条粗线，**下眼睑常常省略**；高光 1–2 点，白色硬边；虹膜基本单色；睫毛不分组 |
| **脸** | 长脸、尖下巴、细长脖子；鼻梁一根短竖线＋鼻头一个小点；嘴很小且靠下；眉毛细或被刘海遮住（贞本义行式「无眉」） |
| **色** | 赛璐璐平涂＋1–2 层阴影；**阴影偏蓝紫（冷）**；肤色偏白；高光硬边；整体低饱和 |
| **身** | 8–9 头身；肩窄；手脚细长；站姿僵硬，像「设定图」；衣服褶皱少 |
| **发** | 片状分组；边缘锐利；高光是连续白带；发梢少分叉 |
| **演** | 正面／侧面的「设定图式」构图；表情克制；大量静止长镜 |
| **质** | 赛璐璐的塑料感；偶尔出现厚涂（游戏、异质作品） |
| **比例** | 头小、眼大、腿长；四肢被拉长 |

## 三个关键做法

1. **把阴影调冷**。赛璐璐的阴影本来是「加深的固有色」，这一期开始系统性地往蓝紫偏——人物的皮肤因此显得「缺血」，这是「世纪末的冷」最直接的技术来源。
2. **省掉下眼睑**。只画上眼睑，眼睛就变成一个「开口向下的容器」，视线失去落点，人物显得空。这是《EVA》《玲音》共用的手法。
3. **用白带画头发高光**。不是画「光」，是画「一条白色的带子」——效率极高，也因此成为 1990 年代动画最好认的特征。

## 代表作者

- **貞本義行**（《EVA》）：极细线、无眉、眼神空洞、身体像被抽掉重量。他画的不是「美」，是「不适」。
- **結城信輝**（《天空之艾斯嘉科尼》）：端正、鼻梁挺、下巴清晰、服饰厚重——与贞本完全相反的一极。
- **川元利浩**（《星际牛仔》）：写实比例、成人五官、松弛线条。他证明「不萌」也能成立。
- **安倍吉俊**（《玲音》）：比贞本更细、更白、更空，把「内向」推到极端。
- **長谷川眞也**（《少女革命》）：锐角、平面、剧场性——脸被当作图形使用。
- **CLAMP**（《魔卡少女樱》）：大眼、细肢、装饰性，供给此后二十年的「可爱」语汇。

## 同期的异质探索

| 探索 | 做法 | 后来变成什么 |
|---|---|---|
| 《玲音》 | 极细线＋无表情＋病态白 | 2010 年代的「空气感」、VOFAN 的光 |
| 《少女革命》 | 锐角、平面化、舞台光 | 《化物语》式的平面构图 |
| 《幽灵公主》 | 圆脸、粗轮廓、以动作塑造人物 | 吉卜力路线，作为「大众基准」长期存在 |
| 《合金装备》《女神侧身像》 | 厚涂、水墨、材质感 | 游戏人物设计的「暗黑高级感」一支 |

## 与前／后一期的差异

- **向前**：1990 年代前半的「大眼睛＋健康肤色」（《美少女战士》）在这一期被**变冷、变瘦、变空**。同样的比例，情绪反转。
- **向后**：P2 会把「冷」换成「艳」，把「瘦」换成「圆」，把「怕断的线」换成「会呼吸的线」。P1 的赛璐璐冷阴影在 P2 基本消失。

> **一句话**：P1 是「把脸画薄」的四年——薄到能透出心理。

# P2｜2000–2004：「萌」的语法化

## 时代条件

数字作画全面替代赛璐璐。上色变成图层操作，「动画涂＋高光」在几年内被统一成工业标准。美少女游戏市场扩大并开始改编 TV 动画（《To Heart》1999），深夜档扩张，DVD 让「可以反复看的脸」变得重要。同人文化与早期网络社区开始生产「角色分类学」。

## 主流画像

| 维度 | 该期的普遍做法 |
|---|---|
| **线** | 开始出现「入り抜き」；线色转向深褐／深蓝；仍细但更软；少数作品开始用色线（色トレス） |
| **眼** | 占脸 1/3–1/2；上眼睑粗＋下眼睑细；高光 2–3 点（大圆＋小圆）；虹膜开始两色渐变；**平井脸：眼距宽、外眼角下垂、鼻梁消失** |
| **脸** | 圆润化开始；鼻梁只剩鼻头一个点；下巴变短；脸部阴影被压平 |
| **色** | 动画涂＋高光标准化；肤色加腮红；阴影仍偏冷但更艳；高光出现「天使环」 |
| **身** | 6–7 头身；细腰细腿；体型两极（幼态／丰满） |
| **发** | 高光带变成「天使の輪」（环状高光）；发梢分叉增多；发色开始高饱和 |
| **演** | 正面特写增多；表情符号化（汗滴、青筋、脸红） |
| **质** | 平涂为主；厚涂只出现在游戏与异质作品 |
| **比例** | 头变大、眼更大、身体缩短 |

## 三个关键做法

1. **标准化涂法**。底色 → 一层阴影 → 高光，三步完成。「阴影只有一层」是这个时代最明显的技术特征，也是它看起来「干净」的原因。
2. **把鼻梁删掉**。平井久司的做法：不画鼻梁的线，只留鼻头的一个点。副作用是脸变平、眼距变宽——这恰好符合「可爱」的几何。
3. **给眼睛加「天使环」**。虹膜上方一圈亮色带，模拟眼球的反光。它是 P2 最有效的「萌」装置，也让角色在低分辨率屏幕上依然醒目。

## 代表作者

- **平井久司**（《Argento Soma》2000、《高达 SEED》2002）：一个模板的诞生与普及。两年内从「新」变成「全民」。
- **羽海野チカ**（《蜂蜜与四叶草》）：水彩式淡彩＋潦草线条，证明「不干净」可以是高级感。
- **村田蓮爾**：极细线、无国籍服饰、复古未来。插画的技术标准被他抬高。
- **大暮維人**（《飞轮少年》）：把线条密度推到「画集」级别。
- **山田章博**（《十二国记》原案）：东方线条、厚重衣装，把「古意」带进大众视野。
- **後藤隆幸**（《攻壳 SAC》）：冷色硬边、写实比例，萌系之外最稳定的成人向主线。

## 同期的异质探索

| 探索 | 做法 | 后来变成什么 |
|---|---|---|
| 《FLCL》(2000) | 剧画式粗线＋动画式变形混用 | 2010 年代「作画派」的直接源头 |
| 《攻壳 SAC》(2002) | 冷色硬边、写实 | 《进击的巨人》式的厚涂写实 |
| 《岩窟王》(2004) | 纹理贴图取代平涂 | 2010 年代的「材质实验」、ufotable 的数字特效 |
| 《真·女神转生 III》(2003) | 金属质感、恶魔轮廓 | 《尼尔》系列的「暗黑高级感」 |
| 轻小说插画（いとうのいぢ 等） | 高饱和发色＋大眼睛 | P3 的「插画反向定义动画」 |

## 与前／后一期的差异

- **向前**：P1 的「薄」变成 P2 的「平」；P1 的「冷」变成 P2 的「艳」；P1 的「怕断的线」变成 P2 的「会呼吸的线」。
- **向后**：P3 会把 P2 的「标准件」升级成「品牌脸」——同样是那套零件，但开始强调「这家公司的脸」。

> **一句话**：P2 是「把脸压平、并把可爱标准化」的五年。

# P3｜2005–2009：角色主导的时代

## 时代条件

深夜动画数量激增；轻小说改编潮（《凉宫春日》《灼眼的夏娜》《零之使魔》）；niconico（2006）与初音未来（2007）让「画师」第一次有了独立的粉丝；DVD／BD 让高精细作画有回报；京都动画建立起全数字、可复用的作画体系。

## 主流画像

| 维度 | 该期的普遍做法 |
|---|---|
| **线** | 更细更软；轮廓线颜色变浅（棕／灰）；色トレス普及；线宽变化夸张，「线会随情绪伸缩」 |
| **眼** | 极大（接近半张脸）；高光 2–3 点＋瞳孔渐变；睫毛分组（3–4 根一簇）；眉毛细短 |
| **脸** | 圆脸、短下巴、**极小鼻口**（鼻头一个点＋嘴一条短线）；脸颊有「团子」感；脸宽／脸长比达到历史最大 |
| **色** | 透明上色（薄涂多层）；高光多层；肤色透亮；阴影用暖色；整体高明度 |
| **身** | 5–6 头身；细腿；「くの字」姿势；手部简化 |
| **发** | 大体积、柔软、发梢细碎；高光带宽；呆毛成为标配 |
| **演** | 特写＋停顿；「颜艺」；静止画式的美少女构图 |
| **质** | 透明／玻璃感；插画侧出现水彩感 |
| **比例** | 头最大、身体最短——「萌」的极值期 |

## 三个关键做法

1. **透明上色**。把阴影层减少、颜色加亮、边缘柔化，让人物看起来「透光」。技术上依赖数字图层的透明度与滤色，审美上则直接对应「可爱＝干净」。
2. **压缩鼻口**。鼻头一个点、嘴一条短线，甚至只留一个「<」。脸部信息量降到最低，眼睛的信息量升到最高——**注意力的强行分配**。
3. **给公司做脸**。京阿尼的「京阿尼脸」、Key 的「Key 脸」、SHAFT 的「新房式平面」。角色设计第一次成为公司品牌的一部分。

## 代表作者

- **荒谷朋恵 / 池田晶子 / 堀口悠紀子**（京阿尼三代）：从《AIR》的玻璃感，到《凉宫》的圆脸，到《轻音》的极小鼻口——同一种「可爱」的三个版本。
- **田中将賀**（《龙与虎》2008 起）：圆润＋高光＋「会哭的眼睛」。他是此后十五年最稳定的主流脸。
- **渡辺明夫**（《化物语》）：色块分割、平面化，人物设计变成版面设计。
- **江端里沙**（《超时空要塞F》）：偶像脸，把发型体积与光泽做成卖点。
- **吉田健一**（《交响诗篇》）：松弛线条、生活感，「能呼吸的线」。
- **KEI / いとうのいぢ / VOFAN / かんざきひろ**：插画师侧的四个坐标——角色作者、高饱和、光与空气、动画师兼业。

## 同期的异质探索

| 探索 | 做法 | 后来变成什么 |
|---|---|---|
| 《叛逆的鲁路修》(2006) | CLAMP 原案的长身＋锐角 | 《进击》之前的「反萌系」样本 |
| 《化物语》(2009) | 平面化色块、留白、文字排版 | 2010 年代的「设计感」动画 |
| 《恶之华》(2009) | 写实而令人不适的线条 | 《声之形》《东京喰种》的「真实系」 |
| 《天元突破》(2007) | 极端变形、作画至上 | 《斩服少女》《一拳超人》 |

## 与前／后一期的差异

- **向前**：P2 是「标准件」，P3 是「品牌脸」；P2 的「可爱」是属性，P3 的「可爱」是身份。
- **向后**：P3 把「减笔画」推到极限（《轻音》几乎不画鼻子），P4 只能反向「加信息」——这是三十年间最干净的一次反转。

> **一句话**：P3 是「把脸做成品牌」的五年。

# P4｜2010–2014：信息量爆炸

## 时代条件

BD 与高清电视普及，「细节」第一次能被观众看清；作画监督与原画师开始被观众认识，作画讨论成为网络内容；剧场动画走向高精细；3DCG 开始承担背景与道具；社交网络让「截图」成为传播单位。

## 主流画像

| 维度 | 该期的普遍做法 |
|---|---|
| **线** | 线宽变化更大；色トレス普及；「省线」与「加线」两极并存；线条强调「呼吸」 |
| **眼** | 虹膜分层 3–5 层；多重高光 3–6 点；睫毛逐根；瞳孔形状多样（星、十字、猫眼） |
| **脸** | 脸颊有体积；下颌有转折；**鼻梁回归**（一根细线＋鼻头阴影）；嘴唇有高光 |
| **色** | 肌肤多层渐变（血色／阴影／高光）；环境光；空气远近；高饱和但不「脏」 |
| **身** | 6–8 头身；关节与肌肉有暗示；手部描写变细 |
| **发** | 发丝分级（前发／侧发／后发／呆毛）；高光分层（天使环＋点光） |
| **演** | 镜头感（鱼眼、浅景深、逆光）；构图的「摄影化」 |
| **质** | 高精细；材质分区（布料／金属／皮肤） |
| **比例** | 头身回升，五官间距缩小，更接近真人 |

## 三个关键做法

1. **给虹膜分层**。从「一个颜色的圆」变成「底色＋内圈＋瞳孔＋边缘光」四层。这是 P4 最标志性的技术动作，也是「信息量」一词的来源。
2. **让皮肤透光**。在脸颊、鼻尖、耳廓加暖色渐变，模拟皮下血色。人物因此从「符号」变成「有身体的东西」。
3. **用高光计时**。高光的数量与位置开始承担情绪功能——眼睛湿润时高光变多、变散。这是《未闻花名》之后的标准做法。

## 代表作者

- **西屋太志**（《冰菓》2012）：把京阿尼的脸从「记号」改成「信息」。虹膜分层、睫毛分组、皮肤通透——十年的分水岭。
- **田中将賀**（《未闻花名》2011）：把「会哭的眼睛」定型，情感向动画从此有标准表情。
- **足立慎吾**（《刀剑神域》2012）：游戏感人物，皮肤像被光照过，服装有材质分区。
- **浅野恭司**（《进击的巨人》2013）：粗线＋厚涂＋强阴影，与萌系正面相反。
- **中嶋敦子**（《东京喰种》2014）：病态美形，恐怖与美少年缝合。
- **桂正和**（《老虎和兔子》2011）：写实美形进入英雄题材，明确瞄准成年观众。

## 同期的异质探索

| 探索 | 做法 | 后来变成什么 |
|---|---|---|
| 《四叠半神话大系》(2010) | 扭曲透视、变形人物 | 《春宵苦短》《映像研》的「设计感」 |
| 《魔法少女小圆》(2011) | 圆脸萌被拆解成恐怖 | 《来自深渊》式的「可爱×残酷」 |
| 《斩服少女》(2013) | 极端夸张体态 | 《赛马娘》《孤独摇滚》的「作画狂欢」 |
| huke（《命运石之门》原案） | 厚涂、暗色、金属 | 2010 年代插画的「材质派」 |

## 与前／后一期的差异

- **向前**：P3 是「减笔画」，P4 是「加信息」。同一张脸，从「读符号」变成「看质感」。
- **向后**：P4 把「信息量」卷到边际递减，P5 只能分裂——有人继续加（《紫罗兰》），有人反向减（《利兹与青鸟》），有人换材质（《鬼灭》）。

> **一句话**：P4 是「把脸画满」的五年。

# P5｜2015–2019：全球化与样式分裂

## 时代条件

海外配信（Netflix、Crunchyroll）改变预算结构；剧场动画票房创纪录；中国与韩国的工作室大量参与中割与上色；3DCG 成为常规工具；Twitter／Instagram 让「一张截图」成为作品的传播单位，构图开始为「被截图」优化。

## 主流画像：不再是「一个」主流

P5 之后，「主流」必须写成三条并行路线。

| 维度 | A. 力量派（太线） | B. 和风派（浮世绘） | C. 极简派（留白） |
|---|---|---|---|
| **线** | 粗、有顿挫、强调重量 | 细而有笔意，带纹样 | 极细、极省，甚至只留轮廓 |
| **眼** | 眼白大、瞳孔小、眼神狠 | 眼型上挑、瞳孔有纹样 | 一条线＋一个点 |
| **脸** | 方下颌、宽鼻、表情夸张 | 细长脸、狐狸眼、和风妆 | 留白，靠微表情 |
| **色** | 高对比、重阴影 | 高饱和＋数字特效（光、火、水） | 低饱和、水彩感 |
| **身** | 肌肉与动势优先 | 衣纹与姿态优先 | 关节与呼吸优先 |
| **发** | 块状、硬边 | 细腻、有纹样 | 大色块、少分组 |
| **代表** | 《我的英雄学院》(2016) | 《鬼灭之刃》(2019) | 《利兹与青鸟》(2018) |

## 三个关键做法

1. **太线（太い線）**。马越嘉彦把美式漫画的粗轮廓带回日式动画：线不是因为「画得重」，而是因为「要撑住动作」。这是对 P3「极细线」的正面反叛。
2. **数字特效替代材质**。ufotable 用粒子、光晕、镜头光代替手绘的材质表现。人物本身不必画得更细，**周围的光替他细**。
3. **极简作为高级感**。西屋太志在《利兹与青鸟》里把《冰菓》的信息量收回去，只留距离与微表情。这说明「信息量」不是单向进步，而是可逆的选择。

## 代表作者

- **馬越嘉彦**（《我的英雄学院》）：太线＋弹性变形，把力量感接进日式人物。
- **松島晃**（《鬼灭之刃》）：浮世绘式的线＋数字特效，「和风」成为全球语汇。
- **高瀬亜貴子**（《紫罗兰永恒花园》）：信息量的极限，虹膜分层、发丝分级、每根睫毛都有阴影。
- **西屋太志**（《利兹与青鸟》）：对上一期的自我反驳——极简、留白、微表情。
- **黄瀬和哉**（《来自深渊》）：可爱画风×残酷世界，萌系被当作诱饵。
- **米山舞**：动画师转插画师，把分镜、镜头与光的逻辑带进单张画。

## 同期的异质探索

| 探索 | 做法 | 后来变成什么 |
|---|---|---|
| 《pop子和pipi美的日常》(2018) | 故意粗糙的「梗图脸」 | SNS 时代的 meme 美学 |
| 《宝石之国》(2017) | 全 3DCG 的「赛璐璐脸」 | 《少女乐队呐喊》的手绘感 CG |
| 《为美好的世界献上祝福！》(2016) | 刻意崩坏的线条 | 「反精致」成为喜剧语言 |
| 《蓝色时期》(2017) | 油画笔触、画材感 | 漫画的「材质化」 |

## 与前／后一期的差异

- **向前**：P4 的「信息量」在 P5 被推到极限后分裂成三条路；「主流」这个词第一次失效。
- **向后**：P6 不再追求「统一」，而是让三条路线各自演化，并加入第四、第五条（CG、AI、全球平台）。

> **一句话**：P5 是「主流分裂」的五年。

# P6｜2020–2026：多极化

## 时代条件

疫情改变制作与消费节奏；配信成为主渠道；SNS 与短视频让「一个表情」就能传播整部作品；3DCG 学会手绘的崩坏（《少女乐队呐喊》2024）；中国团队的赛璐璐 3D 成为全球标准（《原神》2020）；生成式 AI（2022 后）开始影响插画与背景生产。

## 主流画像：两极并存

| 维度 | 去装饰派（少） | 符号派（多） | 混血派 |
|---|---|---|---|
| **线** | 极少、极松，「准确的一笔」 | 线为符号服务（星、十字） | 保留传统线但换材质 |
| **眼** | 一条线＋一个点 | 瞳孔里放星星、猫眼、纹样 | 中华风／和风的眼型 |
| **脸** | 下颌清楚、鼻子用阴影 | 表情夸张、颜艺 | 细长脸＋异国妆造 |
| **色** | 极淡水彩或低饱和 | 高饱和撞色 | 高饱和＋摄影 |
| **身** | 写实体感 | 变形、夸张 | CG 体感 |
| **代表** | 《葬送的芙莉莲》(2023) | 《【我推的孩子】》(2023) | 《药屋少女的呢喃》(2023) |

## 三个关键做法

1. **记号回归**。平松祯史在《咒术回战》里刻意省线：五官只留必要的几笔，表情靠符号与留白。这是对 P4「信息量」的反向修正——**从「画满」回到「画准」**。
2. **CG 手绘化**。手岛nari 在《少女乐队呐喊》里让 3D 角色做出手绘般的崩坏与张力。CG 不再是「另一种画风」，而是「同一种画风的工具」。
3. **为小屏幕构图**。角色设计开始考虑竖屏截图、头像裁切、表情包传播。眼睛、发型、配饰被设计成「缩小后仍然可辨」的符号。

## 代表作者

- **平松禎史**（《咒术回战》2020、《咒术回战 0》2021）：从《FLCL》的狂欢回到极简，一个画师三十年的自我修正。
- **長澤礼子**（《葬送的芙莉莲》2023）：「静」——极少的线、极准的微表情，去装饰化成为新主流。
- **平山寛菜**（《【我推的孩子】》2023）：「星瞳」把偶像的眼睛做成 LOGO。
- **けろりら**（《孤独摇滚！》2022）：网络插画师直接进入动画角色设计，表情包语法上电视。
- **恩田尚之**（《胆大党》2024）：动态线条＋复古构图，把 1970–80 年代的怪奇语汇接回现在。
- **モグモ**（《水星的魔女》2022）：同人出身的画师接下国民级 IP，高达主角彻底萌系化。
- **miHoYo / 原神**：非日本团队定义「日式脸」的全球标准。

## 同期的异质探索

| 探索 | 做法 | 意味着什么 |
|---|---|---|
| 《别对映像研出手！》(2020) | 把作画过程本身变成表演 | 手绘动画的「元叙事」 |
| 《pop 子》之后的 meme 脸 | 梗图作为正式画风 | 网络文化与动画的合流 |
| 《拉撒路》(2025) | 美式平面＋日式线条 | 全球化进入画法本身 |
| AI 生成插画 | 过度光滑、平均化的脸 | 反向强化了「手绘的歪」的价值 |

## 与前／后一期的差异

- **向前**：P5 的「分裂」在 P6 变成「多极并存」——没有中心，也没有被挑战的中心。
- **向后**：尚不可知。可以观察到的两个方向是「CG 与手绘彻底合流」和「AI 逼出的手绘自觉」。本项目不做预测。

> **一句话**：P6 是「没有中心」的六年。

# 五条贯穿三十年的长期趋势

## 趋势一：脸是单向的，身体是钟摆

- **脸**：眼睛越来越大（P1→P3 达峰）→ 信息量越来越高（P4）→ 符号化／去装饰（P6）。方向是单向的：**从「像人」走向「像符号」，再走向「像一笔」**。
- **身体**：8–9 头身（P1）→ 6–7（P2）→ 5–6（P3）→ 6–8（P4）→ 多套（P5–P6）。像钟摆，来回摆。
- **解释**：脸承担「辨识」，身体承担「情绪」。辨识只能越来越强，情绪可以来回调。

## 趋势二：鼻子是最好用的年代标记

| 时期 | 鼻子的画法 |
|---|---|
| P1 | 一根短竖线＋鼻头一个点 |
| P2 | 只剩鼻头一个点 |
| P3 | 几乎不画（只留一个「<」） |
| P4 | 一根细线＋鼻头阴影 |
| P5 | 视路线而定（方鼻／细鼻／省略） |
| P6 | 用阴影而非线 |

一张脸只要看鼻子，就能大致判断年代。这是因为鼻子是**信息量与可爱度之间最难平衡的器官**。

## 趋势三：颜色的「层数」在增加，但「饱和度」在分裂

- 层数：1 层阴影（P1）→ 1 层＋高光（P2）→ 多层透明（P3）→ 多层渐变（P4）→ 特效层（P5）→ 摄影层（P6）。
- 饱和度：低（P1）→ 高（P2）→ 中高（P3）→ 高但不脏（P4）→ 两极（P5）→ 撞色与极淡并存（P6）。

## 趋势四：评价标准变了四次

| 时期 | 观众判断「画得好」的标准 |
|---|---|
| P1 | 像不像、酷不酷 |
| P2–P3 | 可不可爱、是不是「那个脸」 |
| P4 | 有没有信息量、够不够精细 |
| P5 | 有没有风格、能不能被截图 |
| P6 | 有没有「那一笔」、是不是手绘 |

## 趋势五：每一次「加」之后，都会有一次「减」

- P3 减笔画 → P4 加信息
- P4 加信息 → P5 出现极简（《利兹与青鸟》）
- P5 分裂 → P6 记号回归（《咒术》）
- **规律**：任何画法在普及后 5–7 年会遇到「反向修正」。这也是本项目把分期定在 4–6 年的原因。

# 反例与争议

写清楚反例，比多加十条论据更能说明研究的诚实。

1. **预算决定画风**。TV 动画的平均预算远低于剧场，很多「风格」其实是「省钱」。判断时要区分「主动的简省」与「被动的崩坏」——《为美好的世界献上祝福！》是前者，多数低成本作品是后者。
2. **主流不等于多数**。P5 之后，电视动画里数量最多的仍是「标准萌系」，只是不再被讨论。研究「演变」时容易高估先锋、低估沉默的大多数。
3. **地域时差**。中国大陆观众的 EVA 记忆是 1999 年（电视播出），日本是 1996 年。本项目以日本首播为准，但承认记忆的时间差会影响「哪一年重要」的判断。
4. **平台差异**。Netflix 投资的作品倾向高精细、低集数；TV 作品倾向低成本、长跑。同一时期可能存在两套完全不同的「标准」。
5. **「日式画风」正在失去国别**。2020 年后，中国、韩国、欧美团队都在生产「日式脸」。继续用「日本」命名这套画法，是历史惯性，不是地理事实。

---

# 结论：三十年只发生了三次真正的转向

如果把六期压缩成一句话，它是这样的：

1. **1996–2004：把脸压平**。从赛璐璐的冷与薄，走向数字的平与艳。可爱被标准化。
2. **2005–2014：把脸做满**。先做成品牌（P3），再做成信息（P4）。极值出现在《轻音》与《冰菓》之间——同一家公司，七年间从「最少」走到「最多」。
3. **2015–2026：把脸拆开**。分成三条路，再分成更多条。没有中心，只有并存。

而这三次转向，每一次都对应着同一件事：**观众看脸的方式变了**——从「看角色」到「看画」，再到「看那一笔」。
