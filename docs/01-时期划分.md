# 时期划分：六期及其依据

> 结论先行：1996–2026 分为 **六期**。分期的目的不是「把三十年切整齐」，而是让每一期内部**有一套可以被共同描述的画法**，期与期之间**有一次可指认的位移**。

---

## 1. 六期总览

| 期 | 年份 | 名称 | 一句话气质 | 主色（设计用） |
|---|---|---|---|---|
| **P1** | 1996–1999 | 赛璐璐的余温 | 人物被画得又瘦又冷，线条怕断 | `#3A5A7A` |
| **P2** | 2000–2004 | 「萌」的语法化 | 五官被拆成零件，可爱第一次有工业标准 | `#D2694F` |
| **P3** | 2005–2009 | 角色主导的时代 | 脸成为品牌，画师第一次站到台前 | `#4E9E86` |
| **P4** | 2010–2014 | 信息量爆炸 | 从「记号」转向「质感」，脸被画满 | `#B23A6B` |
| **P5** | 2015–2019 | 全球化与样式分裂 | 三条路线同时成立，主流消失 | `#4B3F7A` |
| **P6** | 2020–2026 | 多极化 | 没有中心，只有并存的极点 | `#2B6E6B` |

> 起点：**《新世纪福音战士》**（TV 1995-10 至 1996-03；剧场版 1997）。EVA 之前不研究；EVA 本身作为参照系，不占六期席位。

---

## 2. 凭什么这样切：五个驱动变量

画风不是自己变的。它被五件事推着走，而这五件事的节奏**不同步**——分期的位置，就落在它们交错的地方。

| 变量 | 关键变化点 | 对画风的直接后果 |
|---|---|---|
| **制作技术** | 赛璐璐 → 数字上色（1999–2001）→ 全数字作画（2005 后）→ 3DCG 普及（2013 后）→ CG 手绘化（2020 后） | 阴影层数、线的颜色、高光的硬边／软边 |
| **产业结构** | OVA 衰退（1996–2000）→ 深夜动画扩张（2002–2006）→ 制作委员会成熟（2006–2012）→ 配信资本进入（2015 后） | 谁有预算做「高精细」，谁只能做「低成本崩坏」 |
| **受众结构** | 核心宅 → 轻小说读者（2003–2008）→ 女性观众扩大（2008–2015）→ 全球泛用户（2016 后） | 「可爱」的定义权从宅男转向更广的人群 |
| **作者世代** | 60 后（庵野、贞本）→ 70 后（田中、西屋、马越）→ 80 后（平松、米山、长泽）→ 90 后（けろりら、手岛） | 每一代人对「好看」的默认值不同 |
| **传播方式** | 电视 → DVD → niconico（2006）→ Twitter（2009 后）→ 配信与短视频（2018 后） | 画面被截图的尺寸决定构图与高光 |

**分期的判断标准**：当上面至少三个变量在同一年份前后同时换挡，并且画面上出现了可指认的新画法，就切一刀。

---

## 3. 每一刀的落点

### P1｜1996–1999：赛璐璐的余温

**为什么从这里开始**：EVA 在 1996 年 3 月完结。它不是「一部好动画」，而是**第一次让「人物的心理状态」直接决定了线条的粗细与阴影的颜色**。此后四年，行业还在用赛璐璐，但已经知道有另一种画法。

**为什么在 1999 结束**：1999–2000 年，数字上色在 TV 动画里基本替代赛璐璐；同时美少女游戏改编潮开始（《To Heart》1999）。「冷而薄」的画法失去技术基础。

### P2｜2000–2004：「萌」的语法化

**为什么从 2000 开始**：《Argento Soma》（2000）出现「平井脸」，《FLCL》（2000）证明 TV 动画可以承载剧画式的崩坏。数字上色让「一层底色＋一层阴影＋高光」成为可复制的工业流程。

**为什么在 2004 结束**：2004 年已经出现两种超出该期框架的东西——轻小说插画开始反向定义动画脸（いとうのいぢ）、以及《岩窟王》式的贴图实验。2005 年《AIR》把「透明上色」正式带进电视。

### P3｜2005–2009：角色主导的时代

**为什么从 2005 开始**：《AIR》是京阿尼 Key 系的第一部，也是「脸比作品有名」的起点；2006 年《凉宫春日的忧郁》把这种脸变成社会现象。

**为什么在 2009 结束**：2009 年《轻音少女》是「记号化」的顶点——鼻口被压到几乎不存在。再往前推，只能走向「加信息」（P4）或「反记号」（P5）。

### P4｜2010–2014：信息量爆炸

**为什么从 2010 开始**：作画监督与作画本身成为话题（2010 年前后的作画讨论）、BD 高清让「细节」第一次能被观众看清。

**为什么在 2014 结束**：2012 年《冰菓》确立了「信息量」的标准；到 2014 年，这套标准已经在 TV 动画里卷到边际递减，同时 3DCG 开始正面介入（《乐园追放》2014）。

### P5｜2015–2019：全球化与样式分裂

**为什么从 2015 开始**：海外配信收入改变预算结构；《一拳超人》（2015）把「作画」变成可被全球传播的卖点。

**为什么在 2019 结束**：《鬼灭之刃》（2019）用浮世绘式的线＋数字特效，给出了「和风」的全球版本；同一年《天气之子》把「摄影化」推到极致。两条路都走到头了。

### P6｜2020–2026：多极化

**为什么从 2020 开始**：《咒术回战》（2020）出现明确的「记号回归」——线条重新变少；同年《原神》让非日本团队定义「日式脸」的全球标准。疫情改变了制作与消费的节奏。

## 4. 边界是模糊的：三到五年的过渡带

分期不能精确到某一年，因为**一部作品的制作周期是 2–4 年**，画风的变化总是先在小圈子出现，再被大众看见。

| 边界 | 模糊区间 | 过渡标志 | 处理方式 |
|---|---|---|---|
| P1 → P2 | 1999–2000 | 《To Heart》(1999) 已用数字上色；《Argento Soma》(2000) 才出现平井脸 | 归入 P1 的作品允许带 P2 的先声，在条目里注明 |
| P2 → P3 | 2004–2006 | 《岩窟王》(2004) 是 P2 的异质探索；《AIR》(2005) 才把透明上色带入主流 | 2004 归 P2，2005 归 P3 |
| P3 → P4 | 2009–2011 | 《轻音少女》(2009) 是记号顶点；《冰菓》(2012) 才是信息量转向 | 2010–2011 归 P4，但标注「过渡」 |
| P4 → P5 | 2014–2016 | 《乐园追放》(2014) 是 CG 预演；《你的名字。》(2016) 才是全球化标志 | 2015 归 P5 |
| P5 → P6 | 2019–2021 | 《鬼灭》(2019) 是 P5 的收束；《咒术》(2020) 才是 P6 的开端 | 2020 归 P6 |

**因此**：网站上允许同一部作品同时出现在两个时期的「关联」里（如《冰菓》属于 P4，但也是 P3 记号化的终点），这是设计特性，不是数据错误。

---

## 5. 被否定的三种切法

记录「为什么不那样切」，是为了让分期可被质疑。

### 5.1 按十年切（1996–1999 / 2000–2009 / 2010–2019 / 2020–2026）

**问题**：把 2005–2006（京阿尼转向）和 2012（信息量转向）这两次最大的位移切在十年期的正中间。十年是日历的单位，不是画风的单位。

### 5.2 按技术切（赛璐璐 / 数字 / 3DCG）

**问题**：技术边界与画风边界**不同步**。数字上色在 2000 年前后完成，但画风真正「变平」要到 2005 年之后；3DCG 在 2013 年就进入 TV 动画，但直到 2020 年才做出「手绘感」。技术是原因之一，不是分期本身。

### 5.3 按爆款切（EVA / SAO / 鬼灭 / 咒术）

**问题**：爆款是结果，不是原因。用爆款切分会把「一部作品的传播」误当成「一个时代的变化」，并系统性高估大制作、低估低成本作品里的画风实验。

### 5.4 为什么不按作者世代切

作者世代交叠严重：石原立也（60 后）从 2005 一路做到 2015，横跨 P3、P4、P5；米山舞（80 后）2015 年才成为插画界的中心。按世代切会割裂同一个人在同一种画风里的连续演化。

## 6. 同一作者的时间线（分期是否成立的检验）

如果分期是对的，那么**同一个作者在不同期应该画出明显不同的脸**。以下四条时间线是本文最重要的证据。

### 6.1 石原立也 × 京都动画：十年四张脸

| 年份 | 作品 | 脸的变化 |
|---|---|---|
| 2005 | 《AIR》 | 超大眼睛、极细的腿、上色像玻璃；鼻口还在 |
| 2006 | 《凉宫春日的忧郁》 | 圆脸、大眼、透明感；「京阿尼脸」确立 |
| 2012 | 《中二病也要谈恋爱》 | 更圆、更软、鼻口更小；表情变成「可爱演出」 |
| 2015 | 《吹响！上低音号》 | 脸退居其次，身体（手指、膝盖、呼吸）成为主角 |

同一位监督、同一家公司、同一种「可爱」，十年间从「画脸」走到「画身体」。这就是 P3 → P4 → P5 的位移。

### 6.2 田中將贺：主流脸的连续性

《龙与虎》(2008) → 《未闻花名》(2011) → 《你的名字。》(2016) → 《天气之子》(2019) → 《青春猪头少年》剧场版(2026)。
同一种「圆润＋高光＋会哭的眼睛」被连续使用近二十年，说明**主流的连续性比分期更强**——分期描述的是「主流旁边多出了什么」，而不是「主流被替换了」。

### 6.3 副岛成记：从「帅」到「时尚」

《女神异闻录4》(2008) → 《女神异闻录5》(2016) → 《暗喻幻想》(2024)。
高对比平涂 → 红黑剪影 → 宽肩尖下巴的时装感。游戏人物设计在这条线上，从「角色」变成了「平面设计」。

### 6.4 平井久司：一个模板的寿命

《Argento Soma》(2000) → 《高达 SEED》(2002)。
同一套五官在两年内从「新」变成「全民」，再在五年内变成「被吐槽的模板」。**一个画法的生命周期大约是 5–7 年**，这也解释了为什么分期是 4–6 年一段。

## 7. 分期能不能被验证

一个可操作的检验：**盲测**。

- 给一张没有人名、没有标题的人脸截图，能否判断它属于哪一期？
- P1 / P3 / P6 之间应该**一眼可辨**（瘦冷 vs 圆透明 vs 去装饰）。
- P2 / P3 之间、P4 / P5 之间**允许模糊**（这正是过渡带）。
- 如果一张图无法归类，通常是三种情况：①低成本作品（画风被预算压平）；②跨期作者（如田中將贺）；③异质探索（如《岩窟王》《四叠半》）。

> 这条检验也是网站「时期页」的交互设计依据：让用户自己拖两张图对比，比读文字更能理解位移。

---

## 8. 每一期的「当时的人怎么想」

分期不只是事后分类，也要还原当时的自我认知：

- **P1**：观众觉得「动画变难懂了」，业界觉得「EVA 之后深夜档有救了」。
- **P2**：观众开始用「萌」这个词分类角色；业界第一次意识到「角色可以单独卖」。
- **P3**：观众讨论「京阿尼脸」「Key 脸」；插画师开始有粉丝。
- **P4**：观众讨论「作画崩坏」「作画神回」；作画监督有了名字。
- **P5**：观众讨论「这算不算动画」；海外观众第一次大规模参与讨论。
- **P6**：观众讨论「AI 能不能画」；角色在 SNS 上以截图和切片的形式传播。
