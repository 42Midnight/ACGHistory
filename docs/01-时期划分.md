# 六期划分与使用边界

六期是一种组织样本的阅读框架。它不是经过行业统计验证的断代，也不主张某种画法在边界年突然出现或消失。

| 时期 | 年份 | 名称 | 观察入口 |
|---|---|---|---|
| P1 | 1996–1999 | 赛璐璐的余温 | 修长与圆润并行，细线之外还有弹性轮廓。 |
| P2 | 2000–2004 | 『萌』的语法化 | 五官的记号，逐渐形成鲜明的辨识度。 |
| P3 | 2005–2009 | 角色主导的时代 | 角色的脸，成为作品的一种视觉签名。 |
| P4 | 2010–2014 | 信息量爆炸 | 细节增加，简省也继续发生。 |
| P5 | 2015–2019 | 全球化与样式分裂 | 精细、粗线与简笔，走向不同方向。 |
| P6 | 2020–2025 | 多极化 | 没有唯一的新画风，只有更多种画法。 |

EVA计入P1的1996年四席；不研究EVA之前的作品。P6到2025结束。

## 如何检验分期

对同一维度、相近角度与景别的图像做跨期比较，同时保留同期反例。若一个时期内部差异大于时期之间差异，应调整叙述，不强行把作品塞进统一的主流脸。边界允许约一年过渡，但数据归属必须唯一。

## 重要修正

- 《FLCL》2000年版本为OVA，不能写作TV动画。
- 《轻音少女》2009年到《冰菓》2012年相隔三年；角色设计分别为堀口悠纪子、西屋太志，不能写成同一作者的自我反转。
- 制作公司、导演与角色设计师是不同归属层级，不能以「同公司」推论「同一作者」。
- 「数字上色推广」不等于「原画与动画绘制全面数字化」，也不能据工具替换推定人物画风必然变化。
- 不使用「画师第一次有粉丝」「角色设计第一次成为品牌」等缺乏史料的首创断言。
