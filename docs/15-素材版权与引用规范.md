# 图像来源与引用规则

官方公开不等于授予本站转载许可。这里记录材料处理规则，不把任何素材自动判定为低风险或已获许可，不给出跨法域的法律结论。

1. 年度代表图只取官方角色页、官方宣传页、出版社封面页或授权发行平台。必须区分漫画、动画、游戏版本。
2. 数据记录来源页面、原始图片地址、查阅日期、权利信息和用途说明。后续发行材料须注明，不能当作首发年代的原始设定证据。
3. 不收录同人、AI仿图、盗版扫描、连续帧或整话漫画。完整保留图面，不遮挡署名，不加滤镜。压缩不改变原图的色彩风格。
4. 图片与分析对应；站点不提供打包下载按钮。无图时明示待收录，不能以无关图、续作图或仿图补位。
5. 素材需要更换或撤下时，从assets.json移除映射、移除本地图片并重建；复核静态产物和缓存。正式发布前配置实际联系入口，并逐项复核使用条件。

当前是本地审查版本，未完成逐图公开使用条件复核。图像下载脚本只重现已列出的来源，不构成授权证明。
