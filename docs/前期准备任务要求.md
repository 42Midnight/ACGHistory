1. 网站你不负责实现，你只负责确定技术栈和设计。我的粗略想法是：一个页面是以时间线为横轴，鼠标悬停在哪个年份就展示哪个年份的代表（并行展示），然后点击还能查看具体的赏析；另一个页面以不同时期为展示对象，展示对一个时期的研究。

2. 每个年份选出4个有代表性的漫画作品、动画作品、插画画师、游戏等。（一定要有代表性，动画为主，其他为辅助。30年要选出120个代表用于网站展示，其中动画应该至少占据一半）

3. 关于，你应该先给为这30年做划分（时期的年份画风可能并不能精确到某一年），然后研究不同时期大众主流人物画风的特点（举个例子，00年代京阿尼早年的作品Air和10年代的诸如中二病也要谈恋爱的画风差异巨大）

4. 对不同时期的大众主流画风进行概括与解析，比对前后时期的差异以及一个时期下对其他画风的探索
