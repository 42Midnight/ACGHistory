# 待核对事实清单

> 这份清单是**诚实的清单**：它列出我在写 `data/entries.json` 时把握不足的具体字段。
> 原则：宁可标出来，也不要让一个错误的主创名字挂在网站上三年。

**核对优先级**：
- **P0**：影响「画风归属」判断的核心事实（角色设计、监督、制作公司）。
- **P1**：年份与首次公开时间。
- **P2**：标题译名、出版信息。
- **P3**：2026 观察位（本身就会变动）。

**推荐核对源**（按可靠性排序）：
1. 作品官网的 `STAFF & CAST` 页（最准，但有下线风险）。
2. `allcinema`、`日本映画データベース`（动画电影）。
3. `アニメイトタイムズ` 的作品页（含 staff 表）。
4. 日语维基百科（**只作线索，不作最终依据**）。
5. 设定集／画集的版权页（最可靠，但获取成本高）。
