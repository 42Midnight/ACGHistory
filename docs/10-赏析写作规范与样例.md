# 赏析写作规范与样例

> 目的：给 124 个详情页定一个**可批量执行、又不写成百科**的文本模板。前期准备只交付「规范 + 6 篇完整样例」，其余 118 篇留给内容生产阶段。

---

## 1. 一个详情页由什么组成

| 模块 | 字数 | 作用 | 是否必需 |
|---|---|---|---|
| 标题区 | — | 作品名（中／日／英）＋年份＋类别＋主创 | 必需 |
| **一句话** | 20–40 字 | 全页的钩子，必须包含一个可观察的画法 | 必需 |
| **看什么** | 80–150 字 | 把读者的注意力引到具体位置（眼睛、鼻梁、轮廓、上色） | 必需 |
| **拆解** | 250–400 字 | 按维度逐条说明「怎么画的」 | 必需 |
| **为什么是这一年** | 100–180 字 | 时代位置：它解决了前一期留下的什么问题 | 必需 |
| **与相邻期的差异** | 60–120 字 | 一个具体的对比对象（前后各一） | 必需 |
| **可延伸** | 30–80 字 | 2–3 个「下一部该看什么」 | 可选 |
| **出处** | — | 官方图源、访谈、设定集 | 必需（法务） |

总计约 **550–950 字**。超过 1000 字就不是赏析，是论文。

---

## 2. 写作原则

### 2.1 只写「可观察的画法」

- ✅「上眼睑是一条加粗的实线，下眼睑几乎不画，所以视线没有落点。」
- ❌「眼神深邃，充满故事感。」

**检验方法**：把这句话给一个没看过作品的人，他能不能在画面上指出来？不能就删。

### 2.2 每条判断给一个「证据位置」

不写「整体很精致」，写「虹膜分成四层：底色、内圈、瞳孔、边缘光」。

### 2.3 允许不确定

不确定的主创、年份、集数，写成「一般认为」「据设定集」或直接不写。**宁可少一句，不要错一句。**

### 2.4 不写剧情

除非剧情直接改变了画法（例如《魔法少女小圆》的「可爱被拆解」），否则不涉及。

---

## 3. 禁用词与替换表

| 禁用 | 替换为 |
|---|---|
| 精美、细腻、精致 | 具体说：线的粗细、阴影的层数、高光的点数 |
| 神作、封神、天花板 | 说影响：谁在几年后重复了这套画法 |
| 画风独特 | 说差异：与同期哪一部相比，哪里不同 |
| 充满感情 | 说机制：高光变多、眼皮下垂、嘴角压低 |
| 日式画风 | 说具体来源：哪一年、哪一家公司、哪一位角色设计 |
| 很有年代感 | 说标记：鼻子的画法、阴影的色相、头身比 |

## 4. 六篇完整样例（每期一篇）

> 以下六篇同时充当「写作基准」：后续 118 篇的质量，以这六篇为下限。

### 样例一｜P1｜《新世纪福音战士》（1996，动画）

**一句话**：它把「不安」直接画进了线条——极细的轮廓、几乎不存在的眉毛、没有落点的视线。

**看什么**：先看绫波丽的正面特写。注意三件事：她的眉毛在哪里（答案是没有）；鼻梁的线有多长（大约只有鼻头那么长）；脸侧的阴影是什么颜色（偏蓝紫，不是灰）。

**拆解**：
- **线**：贞本义行的轮廓线细而均匀，几乎不做粗细变化。转折处用小圆角收住，所以人物没有「硬边」，整个人像是浮在背景上。
- **眼**：上眼睑一条粗线，下眼睑省略。虹膜单色，高光只有一到两点，白色硬边。因为下眼睑不画，眼睛的下缘是「开着」的，视线没有落点——这是「空」的技术来源。
- **脸**：长脸、尖下巴、细长脖子。鼻子只用一根短竖线加一个点。嘴很小，位置偏下。眉毛被刘海遮住或干脆不画。
- **色**：赛璐璐平涂，一层阴影，阴影色相偏蓝紫。肤色偏白，高光硬边，整体低饱和。这使得人物在暗背景里会「发光」，在亮背景里会「发灰」。
- **身**：八到九头身，肩窄，手脚细长。站姿僵硬，像设定图——这既是预算限制，也恰好符合「被操控的少年」这一主题。

**为什么是这一年**：1996 年 3 月 TV 版完结。在此之前，日式动画的人物是「健康」的：大眼睛、红脸颊、有精神的站姿。EVA 用同一套工艺画出了相反的情绪，证明**画法本身可以承担叙事**。此后四年的「冷与瘦」，都是它的余波。

**与相邻期的差异**：与 1990 年代前半的《美少女战士》相比，比例几乎没变，但阴影变冷、眉毛消失、视线变空；与 2005 年的《AIR》相比，EVA 的眼睛其实不大——它靠「省」制造情绪，而《AIR》靠「加」制造情绪。

**可延伸**：《玲音》（1998）把同一套「空」推到极端；《星际牛仔》（1998）则用写实比例给出了相反的答案。

### 样例二｜P2｜《机动战士高达 SEED》（2002，动画）

**一句话**：平井久司把鼻梁删掉之后，日式动画的脸第一次可以被「批量生产」。

**看什么**：看基拉的正脸。鼻梁的位置有一条极浅的阴影，但没有线；两只眼睛之间的距离，比眼宽还要宽；外眼角是往下垂的。

**拆解**：
- **线**：轮廓线仍然细，但开始有「入り抜き」——起笔重、收笔轻，头发末端会自己变细。这是数字作画带来的手感。
- **眼**：上眼睑加粗，下眼睑用一条极细的线补上（与 P1 的「省略」相反）。虹膜两色渐变，高光两到三点。眼距被拉开，外眼角下垂——这两点合起来制造出「无辜感」。
- **脸**：鼻梁不画线，只在鼻头留一个点。下巴短、脸颊圆，脸的立体感几乎全部由「阴影的形状」而不是「线的位置」来交代。
- **色**：动画涂的标准形态：一层底色、一层阴影、一层高光，肤色加腮红。阴影仍偏冷，但饱和度比 P1 高，所以人物看起来「有血色」。
- **身**：六到七头身，细腰细腿。与机体的厚重形成强烈反差——这是高达系列第一次让「人比机器更轻」。
- **发**：天使环式高光（虹膜上方一圈亮带），发梢分叉变多，发色开始高饱和。

**为什么是这一年**：2000 年的《Argento Soma》是平井脸的第一次成型，2002 年的《SEED》是它的大众化。两年之内，一套五官从「新」变成「全民」，再在五年内变成「被吐槽的模板」——这是研究画法生命周期最好的样本。

**与相邻期的差异**：与 P1 的贞本脸相比，SEED 的脸更圆、更亮、更有血色，但信息量更少（鼻梁都没了）；与 2005 年之后的京阿尼脸相比，SEED 的脸还留着「成年人」的骨架，京阿尼则彻底幼态化。

**可延伸**：同年的《十二国记》给出了完全相反的答案——山田章博的东方线条与厚重衣装，证明「不萌」也可以很美。

### 样例三｜P3｜《轻音少女》（2009，动画）

**一句话**：鼻口被压到几乎不存在，圆脸、透明上色、细腿——「可爱」在这部作品里被压缩到最少的笔画。

**看什么**：看平泽唯的正面。鼻子在哪里（一个点）；嘴有多长（大约眼睛宽度的三分之一）；脸颊的高光是什么形状（一条柔和的白带，不是硬边）。

**拆解**：
- **线**：堀口悠纪子的线极细、极软，轮廓线颜色偏棕而非黑（色トレス）。线的粗细会随情绪变化——惊讶时线会突然变粗，这是「线会演戏」。
- **眼**：占脸接近一半。上眼睑粗、下眼睑细，睫毛三到四根一簇。高光两到三点，虹膜有淡淡的渐变，但整体信息量仍然很低。
- **脸**：圆脸、短下巴、鼻头一个点、嘴一条短线。脸颊有「团子」感，下颌几乎没有转折。脸宽／脸长比达到三十年的最大值。
- **色**：透明上色——阴影层少、颜色亮、边缘柔化。肤色透亮，阴影用暖色。整体高明度，人物像被一盏柔光灯照着。
- **身**：五到六头身，细腿。「くの字」姿势（膝盖内收、重心偏一侧）成为这一期的标志性体态。
- **发**：大体积、柔软、发梢细碎，呆毛是标配。高光带宽，不是一条细线。

**为什么是这一年**：2009 年是「记号化」的顶点。往前一步（再省）就只剩一个点，往后一步只能「加信息」。第二年，京都动画自己就用《冰菓》走了「加」的那条路。

**与相邻期的差异**：与 2005 年的《AIR》相比，脸更圆、鼻口更小、腿更细——同门七年，从「玻璃感」走到「棉花感」；与 2012 年的《中二病》相比，《轻音》的脸还是「安静」的，《中二病》的脸开始「表演可爱」。

**可延伸**：《化物语》（2009）用色块分割给出了另一条路；《恶之华》（2009）则是这一年最刺眼的反面。

### 样例四｜P4｜《冰菓》（2012，动画）

**一句话**：京都动画把脸从「记号」改成「信息」——虹膜分层、睫毛分组、皮肤透光，十年的分水岭。

**看什么**：看千反田爱瑠的眼睛特写。数一下虹膜有几层颜色（底色、内圈、瞳孔、边缘光，至少四层）；看睫毛是不是一根一根分开；看鼻尖有没有一小块暖色的阴影。

**拆解**：
- **线**：线宽变化更大，轮廓线用色トレス融入肤色。省线的地方（脸颊）几乎不画线，加线的地方（发丝、衣褶）密到能看清结构。
- **眼**：虹膜三到五层，高光三到六点，睫毛逐根。瞳孔形状开始有变化（不只是圆）。眼睛不再是「一个圆」，而是一个有前后关系的球体。
- **脸**：脸颊有体积，下颌有转折。鼻梁回归——一根细线加鼻头阴影。嘴唇有高光。人物第一次看起来「有皮肤」，而不是「有颜色」。
- **色**：肌肤多层渐变（血色、阴影、高光），环境光进入人物。高饱和但不脏，这是数字上色技术成熟的标志。
- **身**：六到八头身，关节与肌肉有暗示。手的描写变细——手指的关节开始被画出来。
- **发**：发丝分级（前发／侧发／后发／呆毛），高光分层（天使环＋点光）。

**为什么是这一年**：2010 年前后，BD 与高清电视普及，观众第一次能看清「细节」。作画监督从幕后走到台前，「信息量」成为评价标准。《冰菓》是这套标准最完整的一次执行。

**与相邻期的差异**：与 2009 年的《轻音少女》相比，同样是京都动画，脸从「最少」变成「最多」——这是三十年间最干净的一次自我反转；与 2018 年的《利兹与青鸟》相比，《冰菓》是「加」的顶点，《利兹》是「减」的回归。

**可延伸**：《未闻花名》（2011）把「会哭的眼睛」定型；《进击的巨人》（2013）用粗线与厚涂给出完全相反的答案。

### 样例五｜P5｜《鬼灭之刃》（2019，动画）

**一句话**：浮世绘的线配上数字特效，「和风」第一次成为全球通行的视觉语汇。

**看什么**：看灶门炭治郎拔刀的一帧。注意轮廓线是不是有「笔意」（起笔重、收笔带锋）；看他周围的火焰是画出来的还是算出来的（粒子和光晕，不是手绘）。

**拆解**：
- **线**：松岛晃的线细而有顿挫，带毛笔的起收。衣纹与羽织的格子纹是「纹样」而不是「褶皱」——这是浮世绘的传统。
- **眼**：眼型偏细长，瞳孔里有纹样（不是单纯的高光）。虹膜信息量不低，但被压在「和风」的框架里。
- **脸**：细长脸、狐狸眼、和风妆造。鼻梁用阴影交代，嘴很小。与 P4 的「写实脸」相比，这张脸是「样式化」的。
- **色**：高饱和＋数字特效。ufotable 用粒子、光晕、镜头光代替手绘的材质表现——人物不必画得更细，周围的光替他细。
- **身**：七头身左右，衣纹与姿态优先于肌肉。动作场面靠「势能」而不是解剖。
- **发**：块状、硬边，发色高饱和（炭治郎的红发是符号）。

**为什么是这一年**：2019 年《鬼灭之刃》成为全球现象。它给出的答案不是「更精细」，而是「更有文化辨识度」——在 P4 的信息量竞赛走到边际递减之后，这是另一条出路。

**与相邻期的差异**：与 2016 年的《我的英雄学院》相比，两者都用「粗线」，但马越嘉彦的粗线是美式的力量，松岛晃的细线是日本的笔意；与 2023 年的《葬送的芙莉莲》相比，鬼灭是「加装饰」，芙莉莲是「去装饰」——四年之间，风向又反转了一次。

**可延伸**：《紫罗兰永恒花园》（2018）是同一时期「信息量」的另一个极端；《利兹与青鸟》（2018）则是「极简」的答案。

### 样例六｜P6｜《葬送的芙莉莲》（2023，动画）

**一句话**：长泽礼子用「少」做出「准」——极少的线、极准的微表情，去装饰化成为 2020 年代的新主流。

**看什么**：看芙莉莲的侧脸。数一下她脸上有几条线（眉、上眼睑、鼻梁阴影、嘴，四条以内）；看她的表情变化幅度有多大（几乎为零，但你能读出情绪）。

**拆解**：
- **线**：极少、极松。轮廓线只在必要处出现，很多地方用色块代替线。这不是「省」，是「准」——每一笔都落在结构上。
- **眼**：一条上眼睑线＋一个瞳孔，高光一到两点。信息量远低于 P4，但位置极准。眼睛的「静」是这一期最重要的表情来源。
- **脸**：下颌清楚，鼻子用阴影而非线。脸颊没有多余的线条。脸型偏长，接近真人比例。
- **色**：低饱和、淡水彩感，但关键处（眼睛、耳朵尖）有高光。整体偏「安静」。
- **身**：七到八头身，姿态放松。衣服的褶皱少而准。
- **发**：大色块、少分组，高光弱化。双马尾的体积靠轮廓而不是发丝。

**为什么是这一年**：2020 年代的观众已经被 P4 的「信息量」喂了十年，对「精细」脱敏。芙莉莲给出的答案是反向的：**减少信息，提高准确度**。它同时解决了 TV 动画的预算问题——少画，反而更高级。

**与相邻期的差异**：与 2019 年的《鬼灭之刃》相比，一个加装饰、一个去装饰，相隔四年；与 2012 年的《冰菓》相比，同样是「高品质」，冰菓靠「多」，芙莉莲靠「少」。

**可延伸**：《咒术回战》（2020）是同一方向更早的信号；《孤独摇滚！》（2022）则用「松弛线条＋夸张表情」给出了喜剧向的版本。

## 5. 批量写作的检查清单

写完一篇，逐条打勾：

- [ ] 有没有至少 **3 个可观察的细节**（线的粗细、高光的点数、阴影的色相、头身比）？
- [ ] 「看什么」里有没有告诉读者**先看哪里**？
- [ ] 有没有一个明确的**对比对象**（前一期或后一期）？
- [ ] 有没有出现禁用词表里的词？
- [ ] 主创、年份、集数是否都能在 `17-待核对事实清单.md` 里对应上？
- [ ] 图源与出处是否齐全（见 `15-素材版权与引用规范.md`）？
- [ ] 全文是否在 550–950 字之间？
- [ ] 如果把作品名遮住，读者能不能从文字里认出这是哪个年代？

## 6. 标注层（「看哪里」热点）的规范

详情页的图片上会叠加热点，点开显示一句解释。规范如下：

| 项 | 规范 |
|---|---|
| 数量 | 每张图 3–5 个，不超过 6 个 |
| 位置 | 必须落在**可指认的五官或轮廓**上：眼、鼻、嘴、下颌、发际线、肩线 |
| 文案 | 一句话，≤30 字，必须包含「画法」而不是「感受」 |
| 示例 | ✅「下眼睑不画，视线没有落点」；❌「眼神很空洞」 |
| 数据 | 存为 `annotations: [{x, y, text, dimension}]`，坐标用百分比（0–100） |
