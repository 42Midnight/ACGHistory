# 信息架构与交互设计

> 两个主页面（时间轴、时期）+ 一个支撑页面（详情）+ 一个说明页面（方法）。
> 交互设计的目标只有一个：**让人「看见」画风的变化，而不是「读到」它。**

---

## 1. 站点地图

```
/                       首页：三句话 + 时间轴入口 + 六期色带
/timeline               时间轴页（主页面 1）
/works/{id}             作品详情 / 赏析（124 个静态页）
/periods                时期总览（六张卡片）
/periods/{p1..p6}       时期研究页（主页面 2，六篇长文）
/method                 研究说明：范围、方法、局限、更新日志
/404                    找不到时给出「回到时间轴」的出口
```

**导航**：左上角站名；右上角 `时间轴 / 时期 / 方法` 三个入口。当前页高亮。
**不做**：搜索页、标签聚合页、作者页。第一版用「时期 + 年代 + 类别」筛选代替（见 §7）。

---

## 2. 首页（/）

首页不是目录，是**一次预告**。

| 区块 | 内容 | 设计要点 |
|---|---|---|
| Hero | 大标题「1996–2026 日式 ACG 人物画风」+ 一句副标题 | 背景是一条极细的时间轴，六个色段缓慢流过 |
| 三句话 | 「脸被压平 / 被做满 / 被拆开」 | 对应三次转向，点击跳到对应时期 |
| 六期色带 | 六个时期色块，显示年份与名称 | 点击进时期页；悬停时显示该期「一句话」 |
| 入口 | 「从 1996 开始」→ `/timeline`；「按时期读」→ `/periods` | 两个按钮，不做第三个 |

## 3. 时间轴页（/timeline）——主页面 1

### 3.1 布局（桌面 ≥1200px）

```
┌──────────────────────────────────────────────────────────────┐
│ 站名                                     时间轴 / 时期 / 方法 │
├──────────────────────────────────────────────────────────────┤
│  [P1 色带] [P2 色带] [P3 色带] [P4 色带] [P5 色带] [P6 色带]  │ ← 期色带（吸顶）
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                │
│  │ 卡 1   │ │ 卡 2   │ │ 卡 3   │ │ 卡 4   │  ← 4 张卡并行   │
│  │ 3:4 图 │ │        │ │        │ │        │                │
│  │ 标题   │ │        │ │        │ │        │                │
│  │ 一句话 │ │        │ │        │ │        │                │
│  └────────┘ └────────┘ └────────┘ └────────┘                │
│                                                              │
│  1996 ─┬─ 1997 ─┬─ 1998 ─┬─ 1999 ─┬─ … ─┬─ 2026             │ ← 横轴
│        ▲ 当前年份（滑块）                                     │
├──────────────────────────────────────────────────────────────┤
│  1996  赛璐璐的余温   细线 · 长身 · 冷色     [固定在 1996]    │
└──────────────────────────────────────────────────────────────┘
```

- **期色带**：六段等宽，宽度按年份比例（P1 4 年、P2 5 年、P3 5 年、P4 5 年、P5 5 年、P6 7 年）。悬停某段时轴上的对应年份范围高亮。
- **横轴**：31 个刻度（1996–2026）。每年一个刻度；整十年（2000、2010、2020）刻度更长、字号更大。
- **卡片区**：固定 4 列网格。卡片高度一致，图片 3:4，标题最多两行，一句话最多两行。
- **底部状态条**：显示当前年份、时期名、期关键词。

### 3.2 交互规格

| 交互 | 触发 | 行为 | 时长／缓动 |
|---|---|---|---|
| 悬停年份 | `pointerenter` 在刻度或年份标签上，**延迟 120ms**（避免扫过时闪烁） | 轴上的滑块移动到该年；4 张卡以 40ms 间隔依次淡入 + 上移 8px | 240ms `cubic-bezier(0.2, 0, 0, 1)` |
| 离开 | `pointerleave` 轴区域 | 若未固定，回到上一个「固定」年份；若从未固定，**保持在最后悬停的年份**（不回到空状态） | 180ms |
| 点击年份 | 点击刻度／年份标签 | **固定**该年（卡片不再随鼠标离开而变），状态条出现「已固定」 | 立即 |
| 点击卡片 | 点击卡片任意处 | 进入详情页（View Transition：图片从卡片位置放大到 Hero） | 320ms |
| 键盘 | 焦点在轴上时 `←` `→` | 上一年／下一年；`Home` / `End` 到 1996 / 2026 | 同悬停 |
| 键盘 | 焦点在卡片上时 `Enter` | 进入详情 | 同点击 |
| 键盘 | `Esc` | 取消固定 | 立即 |
| 触屏 | 点年份 | 固定该年；卡片区在下方展开 | 立即 |
| 触屏 | 卡片区左右滑 | 4 张卡横向 snap 滚动（一次一张） | 原生滚动 |
| URL | 年份变化 | `history.replaceState` 写入 `?year=2012`；**不触发页面重载** | — |
| 深链接 | 打开 `?year=2007` | 直接固定到 2007，并滚动到卡片区 | 立即 |

**关键决策**：悬停是「预览」，点击是「固定」。没有固定时，年份跟随鼠标；固定后，鼠标离开不改变内容。这样可以同时满足「扫读」与「细看」。

### 3.3 状态矩阵

| 状态 | 卡片区 | 轴 | 说明 |
|---|---|---|---|
| 初始（无参数） | 显示 1996 的 4 张卡 | 滑块在 1996 | 首屏必须有内容，不能是空白 |
| 悬停中 | 目标年的 4 张卡 | 滑块跟随 | — |
| 已固定 | 固定年的 4 张卡 | 滑块停在固定年，带「图钉」标记 | — |
| 图片加载中 | 卡片显示 LQIP 模糊图 + 骨架线 | — | 图片加载完成后淡入 |
| 年份无数据 | 理论不存在（每年 4 条） | — | 若发生，显示「该年数据待补」 |
| 2026 | 4 张观察卡，带「进行中」角标 | 刻度用虚线 | 与核心数据区分 |
| 减少动效 | 直接切换，无位移 | 直接跳 | `prefers-reduced-motion` |
| 键盘焦点 | 卡片显示 2px 焦点环 | 刻度显示焦点环 | 焦点环不得用 `outline: none` |

### 3.4 移动端（<768px）

```
┌──────────────────────┐
│     站名      菜单    │
├──────────────────────┤
│ ◀ 1996 1997 [1998] … │ ← 年份条：横向滚动，当前年居中放大
├──────────────────────┤
│ ┌──────────────────┐ │
│ │  卡片 1（大图）   │ │
│ └──────────────────┘ │
│ ┌──────────────────┐ │
│ │  卡片 2           │ │
│ └──────────────────┘ │
│   …（纵向排列）       │
├──────────────────────┤
│ 1998 · P1 · 关键词    │
└──────────────────────┘
```

- 年份条用 `scroll-snap-type: x mandatory`；点击年份后自动居中。
- 卡片改为**纵向排列**（不是横滑），因为竖屏下横滑会与浏览器返回手势冲突。
- 期色带在移动端折叠成一条细线（只显示颜色，不显示文字）。

### 3.5 性能约束

- 卡片图：`loading="lazy"`，当前年 + 前后各 1 年的图预取（`<link rel="prefetch">` 或 `new Image()`）。
- 悬停进入 120ms 后才开始请求图片，避免扫过时发起几十个请求。
- 124 条数据（约 45KB JSON）在构建期注入岛屿，不再发请求。
- 切换年份只用 CSS transform + opacity，不触发布局。

## 4. 时期页（/periods/{id}）——主页面 2

### 4.1 结构

```
┌──────────────────────────────────────────────┐
│ P4                                           │ ← 巨号时期编号（背景色）
│ 2010–2014                                    │
│ 信息量爆炸                                    │
│ 瞳的多重高光、肌肤的渐变、「作画」成为话题      │
├──────────────────────────────────────────────┤
│ [时代条件] [主流画像] [关键做法] [代表作者]    │ ← 吸顶子导航
│ [异质探索] [前后差异] [代表作]                │
├──────────────────────────────────────────────┤
│ 01 时代条件      …正文…                       │
│ 02 主流画像      九维度卡片（横向 9 张）       │
│ 03 关键做法      三条，带示意图               │
│ 04 代表作者      4–6 张作者卡                 │
│ 05 异质探索      3 张卡 → 「后来变成」箭头     │
│ 06 前后差异      三栏对比：上一期 / 本期 / 下一期│
│ 07 代表作        20 张缩略图 → 详情页          │
├──────────────────────────────────────────────┤
│ ← P3 角色主导    　      　    P5 全球化 →    │
└──────────────────────────────────────────────┘
```

### 4.2 三个专属组件

**① 九维度卡（FacetGrid）**
每个维度一张小卡：维度名（线／眼／脸／色／身／发／演／质／比例）+ 一句该期的做法 + 一个极简示意图（SVG，非版权图）。
点击卡片 → 展开该维度在**六期之间**的对比（一个小型时间条），让用户立刻看到「这一维度是怎么变的」。

**② 前后差异（PeriodDiff）**
三栏：上一期 / 本期 / 下一期，每栏只写**一个**最关键的差异点。不要写成表格，写成三句话。

**③ 代表作带（WorksStrip）**
20 张缩略图横向排列，按年份排序，时期色作为分隔。悬停显示标题与一句话；点击进详情。

### 4.3 时期页的「对比」组件（可选，第二期）

**CompareSlider**：两张同维度图（如两位画师的眼睛特写）叠放，拖动分割线对比。
这是「看见差异」最有效的交互，优先级仅次于时间轴。第一版可以先用「并排两张图 + 标注」代替。

## 5. 详情页（/works/{id}）

### 5.1 结构

| 区块 | 内容 |
|---|---|
| Hero | 16:9 主图，叠 3–5 个**标注热点**（点开显示一句话） |
| 标题区 | 中文名 / 原名 / 英文名；年份、类别、时期；主创、角色设计、制作 |
| 一句话 | 大号引言样式 |
| 看什么 | 引导读者看具体位置 |
| 拆解 | 按维度分条（线／眼／脸／色／身／发） |
| 为什么是这一年 | 时代位置 |
| 与相邻期的差异 | 一个前、一个后 |
| 可延伸 | 2–3 个链接 |
| 侧栏（桌面） | 维度标签、所属时期、**同年另外 3 件**、出处 |
| 底部 | 同一时期内上一件 / 下一件；「回到时间轴 · 2012」 |

### 5.2 标注热点（AnnotationLayer）

- 数据：`annotations: [{ x, y, text, dimension }]`，坐标为百分比。
- 交互：悬停显示短线 + 文案；点击固定；`Tab` 可遍历。
- 视觉：小圆点 + 细引线，不用弹窗，避免遮挡图片。
- 降级：无 JS 时，热点下方以列表形式显示全部标注（`<noscript>` 或 SSR 静态列表）。

## 6. 方法页（/method）

把「研究怎么做的」公开，是这类站点的可信度来源。

必须包含：范围与排除项、九维度定义、选片四条标准、分期依据、置信度说明、**已知错误与更正记录**、图片版权说明（链接到 `15`）。

## 7. 筛选与检索（第一版的最小方案）

不做搜索框，做**三个筛选器**（放在时间轴页顶部）：

| 筛选器 | 选项 | 行为 |
|---|---|---|
| 类别 | 全部 / 动画 / 漫画 / 游戏 / 插画 | 过滤卡片，非目标类显示为「灰点」而不是消失（保持 4 格结构） |
| 时期 | P1–P6 | 点击后跳到该时期的年份范围 |
| 关键词 | 从 `tags` 生成（细线、太线、平井脸…） | 点击后高亮相关卡片 |

**为什么不做搜索**：124 条数据，用户更容易「按年找」而不是「按词找」。搜索是 YAGNI（见 ADR-004）。

## 9. 动效规范

| 场景 | 属性 | 时长 | 缓动 | 降级 |
|---|---|---|---|---|
| 年份切换 | opacity + translateY(8px) | 240ms | `cubic-bezier(0.2,0,0,1)` | 直接切换 |
| 卡片入场 | opacity + translateY，40ms 间隔 | 240ms | 同上 | 直接显示 |
| 滑块移动 | `left` / `transform` | 240ms | 同上 | 直接跳 |
| 页面切换 | View Transition（图片共享元素） | 320ms | 默认 | 普通跳转 |
| 热点出现 | scale(0.8→1) + opacity | 160ms | ease-out | 直接显示 |
| 悬停卡片 | translateY(-2px) + 阴影加深 | 160ms | ease-out | 无 |

**原则**：所有动效都必须在 `prefers-reduced-motion: reduce` 下失效；动效只用于「解释空间关系」，不用于装饰。

## 10. 无障碍（WCAG 2.2 AA）

1. **年份轴**：`role="tablist"`，每个年份 `role="tab"` + `aria-selected`；卡片区 `role="tabpanel"` + `aria-labelledby`。方向键切换，`Home/End` 跳首尾。
2. **焦点可见**：所有可交互元素有 2px 焦点环，对比度 ≥3:1。
3. **对比度**：正文 ≥4.5:1；大号数字（≥24px）≥3:1。时期色只用于装饰与标签，不用于正文。
4. **图片**：`alt` 写「作品名 + 人物状态」，不写「图片」；纯装饰图 `alt=""`。
5. **动态**：不使用自动播放的轮播；不自动推进年份。
6. **触屏目标**：年份刻度可点区域 ≥44×44px（视觉上可以更细）。
7. **屏幕阅读器**：卡片按 DOM 顺序读，不依赖视觉位置；`aria-live="polite"` 播报「当前年份 2012，4 件代表作」。

## 12. 错误与边界

| 情况 | 处理 |
|---|---|
| `/works/unknown` | 404 页：显示「没找到这件作品」，给出最近 4 个年份的入口 |
| `?year=1800` | 忽略参数，回到 1996，不报错 |
| 图片 404 | 显示占位色块 + 作品名首字，不显示破图 |
| JS 未加载 | 时间轴退化为「年份列表 + 4 列卡片」的静态 HTML（Astro 默认 SSR 输出） |
| 数据字段缺失 | 构建期 Zod 校验失败，**不允许上线** |
