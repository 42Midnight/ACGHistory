# 信息架构与交互（当前实现）

| 路由 | 内容 |
|---|---|
| / | 研究导入、人物样例、六期入口 |
| /timeline/ | 30年时间轴，每年四席 |
| /periods/ | 六期总览 |
| /periods/p1/ 至 /periods/p6/ | 时期正文与本期作品 |
| /works/{id}/ | 120个作品条目，120篇扩展赏析 |
| /method/ | 范围、方法、图源、局限与更正记录 |
| /404.html | 返回时间轴入口 |

## 时间轴

初始显示1996四席。悬停年份延迟120ms预览；点击固定，移出后回到固定年份。无固定年份时保留最后预览。左右箭头前后移动，Home/End跳首尾，Esc取消固定。URL保存year与kind，支持刷新和深链接；非法年份回到1996。取消固定后保留当前内容。

全部、动画、漫画、游戏、插画五档筛选，仅筛选当年作品；无结果有清空筛选入口。选两件作品后开启原生dialog并排对比，允许跨年份选择、移除和清空。对比区显示图源与材料版本。

## 布局与动效

桌面四列；窄屏两列，最窄屏时间轴作品单列，年份条可横向滚动。卡片淡入与轻微上移、颜色反馈；减少动效设置下取消动画与平滑滚动。链接与按钮保留可见焦点，年份选择结果有aria-live播报。

## 图像状态

本地主图按完整画面contain呈现，不自动裁切、不加滤镜；卡片用同一图像的模糊底衬填补比例差。缺少图像明确标为公式图待收录；加载失败保留提示。首页与卡片内不嵌套出处链接，完整出处在作品页显示。
