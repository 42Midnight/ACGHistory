# 技术栈与实施决策

2026-11-04：采用Astro静态输出、TypeScript、原生CSS与局部原生交互。版本由package.json与pnpm-lock.yaml确定。无服务器、数据库、账号或后台。

原方案的React岛屿、Tailwind和Motion不属于功能要求；当前时间轴、筛选、对比与对话框用浏览器能力即可完成，暂不引入这些运行时。通过CSS实现短暂淡入，遵从prefers-reduced-motion。

Astro在构建时生成首页、时间轴、时期总览、6个时期页、120个作品页、方法页与404，共131个页面。作品页无需JavaScript即可阅读；时间轴切换与对比需要JavaScript，无脚本时可从时期目录浏览。

本地审查阶段不注册托管项目、不发布到外部。dist可交给支持静态文件的托管服务；公开前须先完成内容与图源验收。

运行：pnpm install；pnpm dev；pnpm check；pnpm build；pnpm preview。项目脚本关闭Astro匿名遥测，以免构建写入用户配置目录。
