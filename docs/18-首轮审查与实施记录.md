# 首轮审查与实施记录

日期：2026-11-04。结论：研究口径和明显错误已作首轮修订，纯前端站点可本地构建及浏览；素材与逐条研究仍未达到公开内容验收标准。

## 范围决定

依据 [落地要求](assets/落地要求.md)，正式范围为1996—2025，共30年、120件样本、六期；删除2026观察位及对应目录。EVA TV版始于1995、完结于1996，作为明确的首年特例计入1996四席。没有EVA之前的研究章节。

只研究人物画风。九个维度围绕人物线条、眼睛、脸型、用色、身体、头发、表情姿态、人物质感和比例；删改仅讨论背景或制作流程的选片理由。时期用语作为样本阅读假说，不再用未经测量的高光数量、头身比例、历史极值和预算因果充当行业结论。

## 已实现的网站

Astro静态输出，普通CSS与TypeScript交互，无服务端业务与数据库。生成131页：首页、年度时间轴、六期目录、六个时期正文、120个作品详情、研究说明和404。

- 年份轴：120毫秒悬停预览、点击固定、取消固定、前后年、六期跳转；支持左右键、Home、End、Escape，年份和媒介状态写入URL。
- 媒介筛选：显示实际入选数量与空状态，能恢复全部媒介。
- 对比：跨年份选两件作品，打开原生对话框查看图像、版本、主创、维度与短评；可取消、清空、关闭。
- 内容：六期正文、短评与扩展赏析分级、来源链接、归年说明、字段更正记录。
- 视觉：纸色背景、深绿强调、克制过渡；支持减少动态效果。图像完整包含，不裁掉人物、不加滤镜。
- 无JavaScript：仍可通过时期目录浏览作品；时间轴提示启用脚本。

66件样本已配官方或授权发行平台宣传图，30年均有图像。并非全部是首发角色设定：每图注明资料用途与版本。《水星的魔女》原宣传图人物不突出，已换成官网苏莱塔正面图，并标注为现存2023年资料。《EVA》当前为发行平台小尺寸角色图，细节分析仍需更清晰的材料。
