# 2015–2019 年度代表作｜全球化与样式分裂

> 分期：**2015–2019｜全球化与样式分裂——太线、浮世绘、极简，三条路线同时成立**  
> 一句话：海外市场成为主战场，『日本动画脸』被全球消费；同时内部裂成太线派、和风派、极简派，再没有一个统一的主流。  
> 期关键词：太线、浮世绘、极简、海外市场、配信、3DCG、混血

海外市场成为主战场，『日本动画脸』被全球消费；内部却裂成三条互不相让的路线：马越嘉彦式的太线、鬼灭式的和风浮世绘、以及西屋太志/山田尚子式的极简。这一期再没有一个统一的主流。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
