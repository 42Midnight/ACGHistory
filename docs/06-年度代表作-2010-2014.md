# 2010–2014 年度代表作｜信息量爆炸

> 分期：**2010–2014｜信息量爆炸——瞳的多重高光、肌肤的渐变、『作画』成为话题**  
> 一句话：从『记号』转向『信息』：眼睛被画出虹膜层次，皮肤被画出通透感；作画者本人成为被消费的对象。  
> 期关键词：多重高光、肌肤渐变、写实化、作画监督、剧场高精细、镜头感

从『记号』转向『信息』。眼睛被画出虹膜层次，皮肤被画出通透感，作画者本人成为话题。同时，剧场动画与 TV 动画的分辨率差距被拉开，『高精细』成为一种独立的美学主张。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
