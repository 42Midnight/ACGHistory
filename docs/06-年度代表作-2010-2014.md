# 2010–2014 年度代表作｜信息量爆炸

> 分期：**2010–2014｜信息量爆炸——细节增加，简省也继续发生。**
>
> 一句话：部分作品细化虹膜、发束与人物肤色；另一些作品保持平面化与强烈的记号。
> 期关键词：多重高光、肌肤渐变、写实化、作画监督、剧场高精细、镜头感

部分作品细化虹膜、发束与人物肤色；另一些作品保持平面化与强烈的记号。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
