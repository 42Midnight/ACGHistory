# 视觉设计规范

> 设计概念：**「活页研究档案」**。
> 白天像一份可以被翻阅的研究档案（纸、细线、编号、宋体大字），点开作品时切换成**放映模式**（暗底、图片发光）。
> 理由：这个站点的两个动作——「研究」与「观看」——在气质上本来就不同，用两套明暗把它们分开，比用一套强行统一更诚实。

---

## 1. 三个方向与选择

### 方向 A｜活页研究档案（推荐）

纸感米白底、1px 细线、等宽标签、巨号年份数字、宋体标题。时期用六种低饱和色区分。
**优点**：长文可读性最好；图像不被界面抢；气质与「研究」匹配；实现成本低（无重纹理、无 3D）。
**缺点**：不够「二次元」；暗色模式必须单独设计。

### 方向 B｜暗房放映厅

近黑底、图片发光、轻颗粒、聚光灯式悬停。
**优点**：截图与插画效果最好；更「ACG」。
**缺点**：120 个详情页长文在纯暗底上阅读疲劳；中文正文在暗底上的行距需要额外调整。

### 方向 C｜色谱数据站

亮底、六期高饱和色块、图表化、图像占比低。
**优点**：最能突出「演变」这件事；图表好看。
**缺点**：把人物画风做成了 dashboard，失去了「看画」的乐趣。

### 选择：A 为主，采纳 B 的「放映模式」作为详情页 Hero 与图片灯箱

这不是折中，而是分工：
- **研究态**（时间轴、时期页、方法页）＝纸感浅色，信息优先。
- **观看态**（详情页 Hero、图片放大、对比滑块）＝暗底，图片优先。

用户在「读」与「看」之间切换时，背景跟着变——**背景的变化本身就是交互反馈**。

## 2. 色彩系统

### 2.1 基础色（研究态）

| Token | 值 | 用途 | 对比度（对 `--ink`） |
|---|---|---|---|
| `--paper` | `#F7F4EE` | 页面底色 | — |
| `--surface` | `#FFFDF9` | 卡片、浮层 | — |
| `--ink` | `#1A1A1A` | 正文 | 16.4:1 |
| `--ink-muted` | `#6B6560` | 次要文字、元数据 | 5.3:1 |
| `--ink-faint` | `#9A948C` | 占位、禁用 | 3.1:1（仅用于非正文） |
| `--hairline` | `#D9D2C5` | 1px 分隔线、卡片描边 | — |
| `--hairline-strong` | `#B8AE9C` | 强调分隔、轴 | — |
| `--accent-ink` | `#1A1A1A` | 强调文字（不使用彩色文字做正文） | — |

### 2.2 六期主色

| 期 | Token | 值 | 语义 | 白字对比度 | 用法 |
|---|---|---|---|---|---|
| P1 | `--p1` | `#3A5A7A` | 冷蓝：赛璐璐的夜 | 6.6:1 ✅ | 色带、年份标记、图表 |
| P2 | `--p2` | `#D2694F` | 珊瑚：萌的暖 | 3.6:1 ⚠️ | 仅用于图形与 ≥24px 文字 |
| P3 | `--p3` | `#4E9E86` | 青瓷：透明感 | 2.9:1 ❌ | **不承载白字**；用于描边、点、色带 |
| P4 | `--p4` | `#B23A6B` | 洋红：信息量 | 5.2:1 ✅ | 色带、图表 |
| P5 | `--p5` | `#4B3F7A` | 靛紫：全球化 | 8.2:1 ✅ | 色带、图表 |
| P6 | `--p6` | `#2B6E6B` | 深青：多极化 | 5.4:1 ✅ | 色带、图表 |

**使用规则**：
1. 主色**只做图形**（色带、点、线、图表、年份底色），不做正文文字色。
2. 需要彩色底 + 文字时，用 `color-mix(in srgb, var(--p3) 18%, var(--paper))` 做浅底，文字仍用 `--ink`。
3. 同一屏最多出现两个主色（当前期 + 相邻期）。
4. 主色不用于错误/成功等语义状态（那用中性灰 + 图标）。

### 2.3 放映态（详情页 Hero / 灯箱）

| Token | 值 | 用途 |
|---|---|---|
| `--stage-bg` | `#0E0F12` | 暗底 |
| `--stage-ink` | `#E8E4DC` | 暗底文字 |
| `--stage-muted` | `#8E8A84` | 暗底次要文字 |
| `--stage-hairline` | `#2A2C31` | 暗底分隔 |

**切换规则**：进入详情页 Hero 时，整页背景渐变为 `--stage-bg`（240ms）；向下滚动到正文时渐回 `--paper`。渐变用 `background-color` 过渡，不用滤镜。

### 2.4 图表色

九维度使用**同一套灰阶 + 一个主色**，不引入第二套彩虹色，避免与六期色冲突：
`--chart-1` `#1A1A1A`、`--chart-2` `#4A4642`、`--chart-3` `#7C756D`、`--chart-4` `#B8AE9C`、highlight 用当前期主色。

## 3. 字体系统

### 3.1 字体选择

| 用途 | 字体 | 回退 | 加载方式 |
|---|---|---|---|
| **标题／巨号数字** | 思源宋体 Noto Serif SC（700 / 900） | `Songti SC`, `SimSun`, serif | **子集化**后自托管 woff2（只含站内实际出现的字） |
| **正文** | 系统黑体栈 | `-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 不加载 Web Font（中文正文用 Web Font 代价过高） |
| **日文原文** | 系统日文字体 | `"Hiragino Kaku Gothic ProN", "Yu Gothic", "Noto Sans JP", sans-serif` | 不加载 |
| **拉丁／数字** | IBM Plex Sans（或系统 `ui-sans-serif`） | — | 自托管，约 30KB |
| **元数据／编号** | IBM Plex Mono | `ui-monospace, SFMono-Regular` | 与上共用子集 |

**为什么正文不加载中文字体**：一个完整中文字体子集 2–6MB。系统字体在中文环境下已经足够好；只有「标题」需要宋体的气质，而标题字数极少，可以做到 60–120KB 的子集。

### 3.2 字号阶梯

| Token | 尺寸 | 行高 | 用途 |
|---|---|---|---|
| `--fs-display` | 120px（clamp 到 64px） | 0.9 | 时期编号 P4、年份大数字 |
| `--fs-h1` | 48px | 1.15 | 页面主标题 |
| `--fs-h2` | 32px | 1.25 | 章节标题 |
| `--fs-h3` | 22px | 1.4 | 小节标题 |
| `--fs-body` | 17px | 1.85 | 中文正文（长文行距要大） |
| `--fs-small` | 15px | 1.7 | 卡片说明、注释 |
| `--fs-meta` | 13px | 1.5 | 元数据、标签（等宽） |
| `--fs-micro` | 11px | 1.4 | 角标、编号 |

**中文排版规则**：
- 正文每行 **32–38 个汉字**（`max-width: 36em`）。
- 段间距 `0.9em`，段首不缩进（网页习惯）。
- 中文与拉丁／数字之间加 1/4 空格（用 `text-autospace` 或手写 `&hairsp;`）。
- 标点用全角；引号用「」，不用 ""。

### 3.3 数字

- 年份、编号、页码一律用 **等宽数字**（`font-variant-numeric: tabular-nums`），保证纵向对齐。
- 巨号年份用宋体 900，字距 `-0.03em`。

## 4. 栅格与间距

- **8px 基准**：所有间距是 8 的倍数（4 作为半档）。
- **12 栏栅格**：最大宽度 1440px，边距 24px（移动端 20px），栏间距 24px。
- **正文栏**：720px 居中（约 36 汉字）。
- **时间轴卡片区**：4 栏等宽，栏间距 16px。
- **圆角**：卡片 2px（几乎直角，保持档案感）；按钮 2px；标签 999px（胶囊）。
- **描边**：默认 1px `--hairline`；强调 1px `--hairline-strong`；不使用 2px 以上的描边。
- **阴影**：只用于浮层，两级：`0 1px 2px rgba(26,26,26,.06)` 与 `0 8px 24px rgba(26,26,26,.10)`。卡片本身**不用阴影**，用描边。

---

## 5. 图像处理规范

| 项 | 规范 | 理由 |
|---|---|---|
| 比例 | 时间轴卡片 3:4；详情 Hero 16:9；时期页缩略 1:1 | 统一比例，避免布局跳动 |
| 裁切 | 以**人脸为重心**，头顶留白 8–12% | 人物研究站，脸必须在视觉中心 |
| 滤镜 | **禁止**加滤镜、调色、加暗角 | 研究站不能改变被研究的对象 |
| 边框 | 1px `--hairline`，无阴影 | 让图片与纸面区分 |
| 圆角 | 0（直角） | 档案感 |
| 出处标注 | 图片右下角，11px 等宽，`--ink-muted`，不压在人脸上 | 法务与可信度 |
| 占位 | LQIP 模糊图 + 中性底色 | 避免闪白 |
| 暗底展示 | 图片外留 32px 暗边，不加发光 | 发光会让颜色失真 |

## 6. 组件视觉规范

### 6.1 作品卡（WorkCard）

```
┌─────────────────┐
│                 │  ← 3:4 图，直角，1px 描边
│                 │
├─────────────────┤
│ 动画 · 2012      │  ← 11px 等宽，--ink-muted
│ 冰菓             │  ← 17px 宋体/黑体 600，最多 2 行
│ 京都动画          │  ← 13px，--ink-muted
│ 「信息量」的分水岭 │  ← 15px，最多 2 行，--ink
└─────────────────┘
悬停：描边变 --hairline-strong，整体上移 2px（无阴影）
```

### 6.2 年份刻度（YearTick）

- 竖线 1px × 8px（整十年 16px）。
- 年份标签 11px 等宽，默认 `--ink-muted`，当前年 `--ink` + 600。
- 当前年滑块：2px 竖线 × 高度 100%，颜色为当前期主色。
- 固定状态：滑块顶部加一个 4px 圆点。

### 6.3 期色带（PeriodBand）

- 高度 6px，六段，颜色为六期主色（80% 透明度）。
- 悬停段：透明度 100%，上方浮出时期名（13px）。
- 当前段：下方一条 1px 下划线。

### 6.4 标签（Tag）

- 胶囊，1px 描边，透明底，11px 等宽。
- 维度标签用主色的 18% 浅底 + `--ink` 文字。
- 不使用彩色实底 + 白字（对比度不够）。

### 6.5 按钮

| 类型 | 样式 |
|---|---|
| 主按钮 | `--ink` 实底 + `--paper` 文字，2px 圆角，高 44px |
| 次按钮 | 透明底 + 1px `--hairline-strong` 描边 |
| 文字链接 | 下划线偏移 3px，颜色 `--ink`，悬停时下划线加粗 |
| 图标按钮 | 32×32，聚焦时 2px 焦点环 |

### 6.6 表格（九维度 / 数据表）

- 无竖线，只有 1px 横线。
- 表头 11px 等宽大写字母间距 0.08em。
- 行高 48px，单元格内边距 12px 16px。
- 时期列用主色的 8% 浅底，不用满色。

## 7. 动效（与 `12` 一致，此处只定视觉参数）

| 参数 | 值 |
|---|---|
| 标准缓动 | `cubic-bezier(0.2, 0, 0, 1)` |
| 入场 | opacity 0→1，translateY 8px→0，240ms |
| 悬停 | translateY -2px，160ms |
| 页面切换 | View Transition，320ms |
| 背景模式切换 | background-color，240ms |
| 减少动效 | 全部时长 0，只保留 opacity 0.01s |

  --stage-ink: #E8E4DC;
  --stage-muted: #8E8A84;
  --stage-hairline: #2A2C31;

  /* 字号 */

  --fs-h1: 48px;
  --fs-h2: 32px;
  --fs-h3: 22px;
  --fs-body: 17px;
  --fs-small: 15px;
  --fs-meta: 13px;
  --fs-micro: 11px;

  /* 间距（8px 基准） */
  --s-1: 4px;  --s-2: 8px;  --s-3: 12px; --s-4: 16px;
  --s-5: 24px; --s-6: 32px; --s-7: 48px; --s-8: 64px; --s-9: 96px; --s-10: 128px;

  /* 结构 */
  --max-w: 1440px;

## 9. 可访问性检查

| 项 | 要求 | 现状 |
|---|---|---|
| 正文对比度 | ≥4.5:1 | `--ink` on `--paper` = 16.4:1 ✅ |
| 次要文字 | ≥4.5:1 | `--ink-muted` = 5.3:1 ✅ |
| 大号数字 | ≥3:1 | 主色最低 2.9:1（P3）→ **P3 不用作大字号文字** ⚠️ |
| 焦点环 | ≥3:1 且 2px | 用 `--ink` 焦点环 ✅ |
| 不依赖颜色传达信息 | 期名始终有文字 | ✅ |
| 动效可关闭 | `prefers-reduced-motion` | ✅ |
| 触屏目标 | ≥44×44px | 年份刻度加透明热区 ✅ |

## 11. 一张图看懂设计语言

```
纸：    #F7F4EE          ← 90% 的面积
线：    1px #D9D2C5      ← 分隔一切
字：    宋体大字 + 系统黑体正文 + 等宽元数据
色：    只在「时期」上出现，六种，低饱和
图：    直角、无滤镜、带出处
动：    8px 位移 + 240ms，只为解释空间
```

**禁止**：渐变按钮、玻璃拟态、霓虹发光、大圆角卡片、彩色正文、自动轮播、粒子背景。
