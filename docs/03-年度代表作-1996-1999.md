# 1996–1999 年度代表作｜赛璐璐的余温

> 分期：**1996–1999｜赛璐璐的余温——修长与圆润并行，细线之外还有弹性轮廓。**
>
> 一句话：细线、长身、冷色只是部分案例；圆润轮廓、写实五官与装饰性大眼同样存在。
> 期关键词：细线、长身、冷色阴影、记号的瞳、赛璐璐、内向

细线、长身、冷色只是部分案例；圆润轮廓、写实五官与装饰性大眼同样存在。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
