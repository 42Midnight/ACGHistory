# 2000–2004 年度代表作｜『萌』的语法化

> 分期：**2000–2004｜『萌』的语法化——数字化上色定型，五官被拆成可复用的零件**  
> 一句话：全面数字作画落地，涂法统一成『动画涂+高光』；平井脸、ぷに顔、属性标签让『可爱』第一次有了工业标准。  
> 期关键词：数字彩色、动画涂、平井脸、ぷに萌、渐变瞳、属性、美少女游戏

2000 年前后，数字作画全面替代赛璐璐，涂法在几年内被统一成『动画涂＋高光』。副作用是五官被拆成可复用的零件：平井脸、ぷに顔、属性标签。这一期的选片刻意保留『工业标准』与『反工业标准』两条线——《高达 SEED》与《攻壳 SAC》同年，就是最好的对照。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
