# 2000–2004 年度代表作｜『萌』的语法化

> 分期：**2000–2004｜『萌』的语法化——五官的记号，逐渐形成鲜明的辨识度。**
>
> 一句话：大眼与小鼻口在部分样本中突出；写实脸、棱角轮廓与装饰性衣纹提供同期对照。
> 期关键词：数字彩色、动画涂、平井脸、ぷに萌、渐变瞳、属性、美少女游戏

大眼与小鼻口在部分样本中突出；写实脸、棱角轮廓与装饰性衣纹提供同期对照。
