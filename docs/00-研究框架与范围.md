# 研究框架与范围

更新：2026-11-04。以 [落地要求](assets/落地要求.md) 为现行约束，原始前期任务仅保留为历史记录。

## 研究问题

人物的线条、五官、身体、头发与表情如何变化？同一年有哪些并行路线？这些判断对应哪些具体作品与图像？选片是编辑取样，不是市场占比统计，也不以人气排名替代画法分析。

## 范围

- 1996—2025，共30个年份，每年四席，共120件。无2026观察位。
- 以EVA为分界，不设此前作品或前史章节。EVA TV版1995年首播、1996年完结，作为起点特例计入P1的1996年四席。
- 聚焦人形角色，覆盖动画、漫画、游戏、插画。排除背景与场景美术，不专门梳理技术流程；技术最多作为有来源的语境说明。
- 日本作品为主体；「日式」指视觉传统，不等于制作国籍。本轮120件样本均为日本制作；若纳入非日本制作的作品，须单独标注制作地区，不能称为日本IP。

## 九个维度

线条、眼睛、脸型、人物用色、体态、头发、表情与姿态、材质、比例。比较相似角度与景别；不依据单张宣传绘推断全片规律，不使用未经测量的极值与数值。

## 归年与署名

year是研究归属年；与首次公开年不同时，yearNote必须解释。例如《青之箱》连载始于2021，当前取样归2022，属于编辑取样，尚需补传播依据。插画师按指定代表作品的观察节点归年，不表示该年出道。

角色原案、动画角色设计、总作画监督、导演必须区分。verifiedFields只代表已查证字段。confidence为草稿置信判断，不能当成核验状态；verification区分partial与unverified，其他字段不得随一个字段确认而自动升级。

## 局限

每年固定四席会遗漏重要路线。P1没有独立插画席位只是抽样局限，不是「1990年代插画没有大众影响」的历史结论。幸存者偏差、媒介版本差异、后续宣传绘的年代错位都需明确标出。行业因果、直接影响与预算判断须另有资料支持。
