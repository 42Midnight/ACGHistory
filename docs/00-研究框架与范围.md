# 研究框架与范围

> 项目：日式 ACG 人物画风演变（1996–2026）
> 版本：0.1.0 ｜ 更新：2026-11-03 ｜ 状态：前期准备（不实现网站）

---

## 1. 这个项目在回答什么

不是「三十年动画史」，也不是「画师名人堂」。它只回答三个问题：

**Q1（横切）** 某一年，是谁、用什么样的画法，定义了大众眼中「日式人物」的样子？
**Q2（纵切）** 这种画法在三十年间如何位移——什么被保留、什么被丢弃、什么被反转？
**Q3（结构）** 每一个时期里，「主流」之外还有哪些并行的探索，它们后来变成了什么？

配套的一个隐性问题是：**为什么是这些作品？** 所以每一条选片都必须给出「画风代表性」的理由，而不是「人气高」。

## 2. 范围：纳入什么，排除什么

### 2.1 纳入

| 维度 | 纳入 |
|---|---|
| 媒介 | 动画（TV／剧场／OVA）、漫画、游戏（含美少女游戏、JRPG、手游）、插画（含轻小说插画、角色原案、VTuber 设计） |
| 地域 | 日本本土制作；含日本 IP 的海外合作（如中国团队的赛璐璐 3D），但需标注 |
| 对象 | **人形角色**：人类、拟人化角色（兽耳、机械少女、宝石人） |
| 时间 | 1996-01-01 至 2026-11-03；以《EVA》TV 版完结（1996-03）为计时起点 |

### 2.2 排除（重要，避免范围膨胀）

| 排除项 | 说明 | 例外 |
|---|---|---|
| EVA 之前的作品 | 1980s–1995 只作为「前史」在必要时一句话提及，不设条目 | 《EVA》本身作为参照系出现（不计入六期） |
| 背景／场景美术 | 不研究美术监督、背景绘制、色彩设计中的场景部分 | 若背景直接塑造人物的「空气感」（如新海诚的光）可一句带过 |
| 技术流程专章 | 不写「RETAS 怎么用」「摄影怎么合」的教程式内容 | 技术作为**画风成因**出现（如数字上色如何改变阴影厚度） |
| 纯兽／纯机械／纯吉祥物 | 皮卡丘、高达机体、初音之外的纯生物设计 | 拟人化（兽耳娘、机械少女、宝石人）纳入 |
| 非日式作品 | 美漫、迪士尼、韩漫只作为「影响源」提及 | 日本 IP 的海外共制纳入并标注 |
| 剧情／演出／音乐 | 除非直接影响人物的「被观看方式」 | 极少数演出型作品（如《化物语》）可讨论构图 |

### 2.3 一个必须说清楚的边界

「人物画风」= **脸的构造 + 身体的构造 + 线条 + 颜色 + 头发的处理 + 表情的符号系统**。
它不是「画得好看不好看」，也不是「像不像真人」。本研究的判断标准是：**这套画法是否被后来的人重复使用**。

## 3. 九个分析维度

所有条目与时期分析都共用这一套维度，方便横向比较（数据里的 `facet` 字段即取自此处）。

| 代号 | 维度 | 具体看什么 |
|---|---|---|
| `line` | 线 | 线宽是否有变化（入り抜き）、线的颜色（黑／褐／蓝）、是否「色トレス」、线的密度 |
| `eye` | 眼 | 眼占脸的比例、上／下眼睑的处理、高光的点数与形状、虹膜分层、瞳孔符号、睫毛分组 |
| `face` | 脸 | 脸型（圆／尖／长）、下颌转折、鼻梁的有无、鼻头、嘴的大小与位置、脸颊体积 |
| `color` | 色 | 平涂／渐变、阴影层数、阴影色相（冷／暖）、肤色透亮感、高光硬边／软边、环境光 |
| `body` | 身 | 头身比、肩宽、四肢粗细、关节与肌肉的暗示、姿势的「重心」 |
| `hair` | 发 | 分组方式（片状／丝状）、体积、高光形态（天使环／点光）、发梢处理 |
| `staging` | 演 | 人物如何被摆放：构图、留白、镜头、表情的「符号化程度」 |
| `texture` | 质 | 材质感：厚涂／水彩／金属／透明／笔触可见度 |
| `proportion` | 比例 | 头身、五官间距、手脚与身体的比值（与 `body` 的区别：`body` 看体态，`proportion` 看数值比例） |

> 用九个维度而不是「风格标签」，是因为标签（萌、写实、剧画）无法比较；维度可以。

## 4. 选片方法

### 4.1 四条标准（按权重排序）

1. **画风贡献**：它是否提出或固化了一套可被复用的画法？（权重最高）
2. **传播规模**：它是否真的被大众看见（票房／收视／销量／社交传播）？
3. **后继影响**：三年后、十年后还有人在用它吗？
4. **时代辨识度**：把它单独拿出来，能不能认出是哪个年代？

### 4.2 分配规则

- 每年 **4 席**，覆盖动画／漫画／游戏／插画。
- **动画优先**：全局动画占比 ≥50%（实际 60%）；大部分年份 2 部动画，转折年份 3 部。
- **一作一次**：同一作品只出现一次（漫画版与动画版不重复计入）。
- **允许重复作者**：同一创作者可出现 2–3 次，但必须在 `01-时期划分.md` 的「同一作者的时间线」里解释其意义（如石原立也的四个节点）。
- **插画席位按时代分配**：1990 年代插画尚未独立成为大众现象，故 P1 不设插画席位（这是结论，不是遗漏）；P3 插画席位最多（轻小说插画的黄金期）。

### 4.3 关于年份口径（重要）

原始需求写「1996–2026」，但 1996 到 2026 是 **31 个年份**，而「30 年 120 个」对应 **30 个年份**。本项目的处理：

- **核心数据集 = 1996–2025 的 30 年 × 4 = 120 条**（`status: core`）。
- **2026 单独作为「观察位」4 条**（`status: provisional`），因为 2026 年尚未结束，秋番仍在播、剧场版仍有变数。
- 网站上时间轴仍然画到 2026，但 2026 的卡片带「进行中」标记。

若你希望 1996–2026 全部 31 年都算正式条目（124 条），只需把 4 条 `provisional` 改成 `core` 并重新生成文档。

### 4.4 置信度

每条数据带 `confidence`：

- `high`：主创／年份可公开查证且无争议。
- `medium`：主创存在不同说法，或年份归属可争议（如跨年连载）。
- `low`：观察位或信息不足。

**当前核心条目中 `medium` 15 条、无 `low`；2026 观察位另有 `medium` 3 条、`low` 1 条。全部已在 `17-待核对事实清单.md` 逐条列出。**

## 6. 术语表（只收录本项目会用到的）

| 术语 | 含义 |
|---|---|
| **赛璐璐（セル画）** | 在透明胶片上手绘上色的传统动画工艺；色彩边缘锐利、阴影层数少 |
| **动画涂（アニメ塗り）** | 一层底色＋一层阴影＋高光的数字平涂法，2000 年代成为标准 |
| **色トレス（色トレス線）** | 用接近肤色的彩色线条代替黑色轮廓线，让线「消失」在颜色里 |
| **平井颜（平井顔）** | 平井久司式五官：鼻梁几乎不画、眼距拉开、轮廓简化，2000–2005 年最普及 |
| **京阿尼脸（京アニ顔）** | 京都动画 2005–2010 年前后的共通脸型：圆脸、大眼、极小鼻口、透明上色 |
| **记号化** | 把五官压缩成最少的笔画与符号（点、线、星），强调辨识度而非信息量 |
| **信息量** | 同一张脸上叠加的细节数量（虹膜分层、睫毛分组、皮肤渐变），2012 年后成为评价标准 |
| **厚涂** | 用不透明色反复覆盖、保留笔触的画法，与平涂相对 |
| **赛璐璐 3D** | 用 3D 模型＋卡通渲染模拟赛璐璐动画质感的做法 |
| **原案 / 角色设计** | 原案＝提出初始人物形象；角色设计＝把原案转成可动画化的设定（含三面图） |
| **总作画监督** | 统一全片人物画风的人，画风稳定性的实际负责人 |
| **作画** | 指动作与表演的绘制本身；「作画派」指以作画质量为核心卖点的作品与观众 |
| **属性** | ツンデレ、妹、メイド等角色标签，2000 年代后与画风绑定 |

## 7. 局限与争议处理

1. **主观性**：分期与选片必然有判断成分。处理方式是把判断依据写出来（每条的 `why`），而不是假装客观。
2. **幸存者偏差**：被记住的作品不等于当年的主流。我们在 `02` 里用「主流画像」而非「名作清单」来补正。
3. **年份错位**：制作年份、播出年份、海外传播年份常常差 1–2 年。处理方式是设 `yearNote` 字段。
4. **地域视角**：中国大陆观众的「日式画风」记忆受引进时间影响（如《EVA》1999 年才在电视播出）。本项目以**日本本土首播**为准，必要时注明。
5. **2020 年代的不确定性**：AI 生成、平台算法对画风的影响尚未定型，本项目只记录现象，不做预测。
6. **事实风险**：主创姓名与年份存在记错的可能，所有 `medium` 以下条目集中在 `17-待核对事实清单.md`。

前期准备**不实现网站**，但所有产出都按「可被网站直接消费」的格式组织：
