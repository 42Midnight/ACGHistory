# 2020–2026 年度代表作｜多极化

> 分期：**2020–2026｜多极化——记号的再编、CG 的手绘化、平台的算法**  
> 一句话：『可爱』被拆解重组，线条重新变少；3DCG 学会了手绘的崩坏，插画与动画的边界被 SNS 抹平。  
> 期关键词：记号回归、3DCG赛璐璐、VTuber、SNS、平台算法、AI、去装饰

『可爱』被拆解重组，线条重新变少。3DCG 学会了手绘的崩坏，插画与动画的边界被 SNS 抹平，中国团队的『赛璐璐 3D』成为全球审美的最大公约数。这一期的选片偏向『谁能定义下一个十年』。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
