# 2020–2025 年度代表作｜多极化

> 分期：**2020–2025｜多极化——没有唯一的新画风，只有更多种画法。**
>
> 一句话：眼睛记号、松弛表情与材质化角色并存；跨媒介传播让同一时期的差异更加可见。
> 期关键词：记号回归、3DCG赛璐璐、VTuber、SNS、去装饰

眼睛记号、松弛表情与材质化角色并存；跨媒介传播让同一时期的差异更加可见。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
