# 2005–2009 年度代表作｜角色主导的时代

> 分期：**2005–2009｜角色主导的时代——京阿尼的脸、轻小说插画、初音未来**  
> 一句话：角色本身成为作品的卖点；京都动画把脸做成品牌，轻小说插画与初音未来让『画师』第一次站到台前。  
> 期关键词：京阿尼脸、圆脸大眼、透明上色、轻小说插画、VOCALOID、网络黎明

角色第一次比作品更有名。京都动画把脸做成品牌，轻小说插画反向定义动画脸，初音未来则让插画师成为角色的作者。这一期的关键词是『透明感』：上色变薄，眼睛变大，鼻口被压缩到几乎不存在。

> 读法：每行末的『维度』是这件作品最适合用来说明人物画风的哪一面（线、眼、脸、色、身、发、演、质、比例）。详情参见 `02-各时期画风研究.md`；数据源为 `data/entries.json`。
