# 日式 ACG 人物画风演变（1996–2026）

一个以《EVA》为起点的三十年人物画风研究项目。最终产物是一个展示网站：
**时间轴页**（悬停某年 → 并行展示当年 4 件代表作 → 点击看赏析）＋**时期页**（六期长文研究）。
本仓库目前是它的**前期准备**：研究、数据、设计、技术选型。**不含网站实现。**

## 三个关键决策（你可能想改）

### 1. 六期划分

`1996–1999 赛璐璐的余温` → `2000–2004 萌的语法化` → `2005–2009 角色主导` → `2010–2014 信息量爆炸` → `2015–2019 全球化与分裂` → `2020–2026 多极化`。

边界允许 ±1 年模糊，理由与被否定的三种切法（按十年 / 按技术 / 按爆款）写在 [时期划分](docs/01-时期划分.md)。

### 2. 技术栈：Astro + React 岛屿 + 静态输出

理由与四个方案的加权评分见 [技术栈选型](docs/11-技术栈选型.md)。一句话：这是**带局部交互的内容站**，不是 SPA。

## 数据与脚本

```bash
# 校验数据并重新生成 docs/03–09
python scripts/build_docs.py

# 只校验，不写文件（CI 用）
python scripts/build_docs.py --check
```

校验内容：每年恰好 4 条、id 唯一、年份落在时期内、核心 120 条、核心动画 ≥60、作品不重复、类别合法。

**唯一数据源**：`data/entries.json`、`data/periods.json`。改数据 → 重跑脚本 → 文档自动更新。

## 需要你确认的三件事

1. **年份口径**：保持「120 核心 + 4 观察」，还是把 2026 也并入正式（124 条）？
2. **插画席位比例**：目前 8 条（P1 没有、P3 最多）。P1 无插画是研究结论（1990 年代插画尚未独立成为大众现象），不是漏选——这个判断你认可吗？
3. **2026 的 4 条全是动画**：是否要换成「3 动画 + 1 漫画/游戏」？（需要补 2026 年的新连载/新作信息）
