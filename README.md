# 日式 ACG 人物画风演变（1996—2025）

以《EVA》为起点，观察三十年日式 ACG 人物的脸、身体、线条、用色、头发与表情。研究不包含 EVA 之前的作品、背景与场景美术，也不专门梳理制作技术流程。

时间口径遵照 [落地要求](docs/assets/落地要求.md)：1996—2025，共30年。EVA TV版跨1995—1996，以1996年完结作为首年特例；不另设前史。2026观察位已移除。

仓库现有可运行的 **Astro 纯静态展示网站**，本轮为本地审查版本。导航只保留时间轴与六个时期；首页、年度时间轴、六期目录与正文、120件作品详情，加上旧「研究说明」链接的跳转页与404，共131页。时间轴支持悬停预览、点击固定、媒介筛选、键盘导航和跨年份两件作品对比；窄屏采用单列浏览。

## 本地运行

需要 Node.js 22.12+ 与 pnpm。依赖版本以锁文件为准。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:4321/`。

```bash
pnpm check          # 数据、来源字段与素材文件
pnpm check:release  # 公开内容覆盖检查（图像、扩展赏析、来源）
pnpm test           # 6项数据约束回归测试
pnpm build          # 校验并构建至 dist/
pnpm check:site     # 构建后检查全部页面的本地链接、资源、标题与语言
pnpm preview        # 预览 dist/
```

没有 pnpm 命令时，也可在安装依赖后使用 `node scripts/site.mjs dev --host 127.0.0.1`。

素材保留完整画面，记录原始URL、出处页、权利信息与版本说明；后续发行资料不会标作首发年份原始设定。公开图片不等于已取得本站转载授权。图像加载失败时仍保留文字提示。

`pnpm check:release` 检查逐条图像、扩展赏析和来源覆盖；当前通过。该检查只证明字段齐备，不替代逐图公开使用条件复核、主创职务核对与人工内容验收。完整标准见 [实施路线图](docs/16-实施路线图与验收标准.md)。

## 数据与维护

`data/entries.json`、`periods.json` 是样本与时期数据；`assets.json` 存图源；`essays.json` 存扩展赏析；`corrections.json` 存可追溯的字段核对记录。网站直接消费这些文件。

```bash
python scripts/build_docs.py          # 校验并重新生成 docs/03—08
python scripts/build_docs.py --check  # 只校验
python scripts/check_assets.py        # JSON、线框SVG、Markdown内部链接
```

`scripts/collect-catalog.mjs`、`download-catalog.mjs`、`download-official.mjs` 用于整理和获取已选择的官方材料，运行需要联网；下载成功不替代人工版本与用途核查。`src/` 为站点代码，`public/images/` 为本地图像，`dist/` 为构建产物（不纳入Git）。
